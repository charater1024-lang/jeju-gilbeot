# 제주 길벗 v23 운영 모델

사용자 화면에서 운영하는 모델은 이전부터 정해진 평가의 관측 범위와 허용오차를 그대로 사용합니다. 예측과 작성 질의 검색은 평가 대상이 다르므로 각 지표와 분모를 함께 표시합니다.

| 기능 | 운영 결과 | 검증 범위 |
|---|---:|---|
| 집단별 8업종 소비 구성비 | **93.75% (270/288)** | 기존 ±1퍼센트포인트. 동일 평가에서 87.50%보다 6.25퍼센트포인트 상승. 평균 절대오차 0.426111 → 0.328038퍼센트포인트. |
| 세부 외식업종 구성비 | **90.68% (1,790/1,974)** | 기존 ±0.25퍼센트포인트. 평균 절대오차 0.097197퍼센트포인트. |
| 공식 관광지 소개 찾기 | **22/22 (100%)** | 동결된 작성 질의. 정답의 첫 결과 노출과 지원하지 않는 질문의 빈 응답을 평가. 실제 이용자 검색의 정확도는 미입증. |

1048은 두 집단의 공통 계절성과 완만한 추세를 조합한 릿지 후보 96개를 비교했습니다. 시간순 검증에서 선정한 후보를 고정한 뒤 2024년 1월~2025년 6월의 기존 288셀 시험에서 평가했습니다. 선정 후보는 시간순 검증에서 264/288을 기록했습니다. 같은 후보를 2023년 12월까지의 자료로 적합해 시험에서 270/288을 기록했습니다. 운영 모델은 설정을 고정하고 2018년 1월~2025년 6월 전체 관측으로 재적합한 월별 구성비입니다. 이미 보고한 시험을 다시 사용한 후향평가이며, 미래 관측으로 한 독립 평가는 별도로 필요합니다.

시간대별 승차 82.53%와 통계 노선코드별 승차 48.18%를 서비스에서 제외했습니다. 두 예측 API는 410으로 응답합니다. 기존 자동 문장 도우미는 전체 요청 처리의 고정 작성 문장 시험에서 49/60(81.67%)이었습니다. 명시적인 출발지·시간·조건 입력으로 일정을 만들고, 공식 소개 검색은 별도 입력으로 사용합니다.

관광 68.18%, 여행 맥락 72.22% 및 운영 범위의 평가 근거가 부족한 음식 랭킹은 운영에서 제외했습니다. 지도와 목록에서는 교차확인한 명부의 이름·분류·주소와 선택한 거리·시간·지역을 사용합니다. 이전 출처 검증, 위치 동의와 출발지 확인은 계속 적용합니다. 실자료 학습과 독립 평가를 재현할 수 있도록 기존 모델과 시험 원본을 보관합니다.

1048 실험은 학습용 Python에서 `scripts/experiment_audience_v23.py --help`로 확인할 수 있습니다. `models_candidates_v23/audience/`의 동결 기준, 선정 명세, 결과와 운영 프로필은 해시로 대조합니다. 이전 평가 [v20 보고서](모델다양화_v20/전체실험_결과보고.md)와 [API 예보 실험](AI사용과_API검증.md)을 참조합니다.
