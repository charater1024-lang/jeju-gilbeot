# 결과 설명 프롬프트 설계

현재 시제품의 설명은 템플릿으로 생성한다. 아래는 선택적 LLM을 위한 제약이다.

추천 일정과 연결된 evidence만 읽고 사용자의 언어로 설명한다. 예측·관측·가정을 각각 구별한다. 지역 소비 점수는 지역 인기 맥락이며 개별 식당 평점이 아니다. 방문 순서가 관측 데이터에서 나온 경우에만 실제 인기 동선이라고 말한다. 비용·교통·영업의 불확실성을 짧게 밝힌다. 근거가 없는 평점·대기시간·예약 가능·영업 여부를 추가하지 않는다.

각 추천 이유는 이용한 조건과 source_id를 연결한다. 합성 모드이면 설명 첫머리에 가상 자료 시연이라고 명시한다. 입력 JSON에 없는 수치와 상호를 생성하지 않는다.
