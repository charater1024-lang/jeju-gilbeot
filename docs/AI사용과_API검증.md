# 제주 길벗에서 AI를 쓰는 곳과 실시간 API 검증

이 문서는 v20 서비스의 평가·API 검증 기록입니다. [현재 운영 모델](운영모델_v23.md)을 별도로 확인할 수 있습니다.

2026년 11월 6일 기준. 서비스는 로컬 CPU에서 검색·요청 분류·예측을 실행합니다. 아래 9개 학습 요소는 현재 호출 경로에서 사용합니다.

| 화면 또는 요청 | 학습한 부분 | 결과에 쓰이는 방식 |
|---|---|---|
| 홈, 지도·먹거리의 관광 검색 | 관광지 TF-IDF와 문자 검색 재정렬 | 출처가 확인된 후보를 검색어 관련도 순으로 보여 줍니다. 위치를 지정하지 않은 일반 첫 페이지 검색에서 조건에 맞으면 기존 상위 5개 후보의 순서를 다듬습니다. |
| 지도·먹거리의 음식 취향 검색 | 음식점 TF-IDF | 업소 이름·업종·태그와 질의를 비교합니다. 지역·거리·좌표 조건은 별도로 적용합니다. |
| 내 여행의 한 문장 도우미 | 문자 나이브 베이즈 | 일정 만들기·수정·검색·소비·승차 등 요청 종류를 분류합니다. 날짜, 출발지와 시간 같은 조건은 규칙으로 읽습니다. |
| 도우미의 관광지 근거 검색 | 공식 소개 자료 TF-IDF | 요청과 관련 있는 관광지 소개 근거를 찾습니다. |
| 지도·먹거리의 집단별 소비 경향 | 1048 계절 릿지 회귀 | 선택 월·집단의 업종별 이용건수 비중을 추정합니다. |
| 내 여행의 시간대별 이동 참고 | 512 달력 회귀 | 제주 전체의 과거 시간대별 일반승차 패턴을 추정합니다. |
| 자료 비교의 버스 노선 이용 경향 | 561 최근 가중 요일 중앙값 | 같은 통계 노선코드의 과거 승차를 학습해 하루 이용량 참고치를 냅니다. |
| 자료 비교의 세부 외식업종 | 1047 계절 릿지 회귀 | 선택 월의 세부 외식업종 이용건수 비중을 추정합니다. |
| 자료 비교의 걷기·해변·접근성·편의시설 | 여행 자료 TF-IDF | 검색어와 관련 있는 기록을 찾습니다. 거리, 최대 소요시간 등은 제공된 필드로 비교합니다. |

TF-IDF는 자료 모음에서 어떤 단어가 특정 기록을 잘 구분하는지 계산하는 방식입니다. 자동 코스는 관광 검색 결과를 받아 출처, 출발·복귀 시간, 방문 조건과 도로를 규칙으로 확인하고 가능한 조합을 탐색합니다. 길벗 상담은 준비된 답변과 규칙을 중심으로 동작하고, 장소를 찾을 때는 기존 검색 모델을 재사용합니다. 서비스는 LLM 없이 동작하며, LSTM과 최근 승차 기록을 쓰는 부스팅은 [별도 실험](모델다양화_v21/승차_추가정보_실험.md)입니다.

실행 코드와 내장 Python으로 호출을 확인했습니다. 예를 들어 `201-14`의 `2026-11-06` 조회는 현재 서비스에서 `38.0명/일`을 반환합니다. 관측치의 범위와 평가 지표는 사이트의 **데이터 안내 → 모델 조합 비교**에서 볼 수 있습니다. 검색과 분류의 작성 질의 시험은 예측 모델의 허용오차 비율 및 실제 사용자 평가와 구분합니다.

## 실제로 받아서 시험한 예보

제주시 공개 기준점에서 NOAA GFS의 기온·강수·풍속을 [Open-Meteo Previous Runs API](https://open-meteo.com/en/docs/previous-runs-api)로 조회했습니다. 각 유효 시각보다 48시간 앞선 모델 초기화 시점의 예보를 사용했습니다. 2024-01-01~2025-10-19 중 세 값이 24시간 모두 있는 638일을 사용했습니다. 2026-11-06~11-07의 예보도 같은 API에서 변수마다 48시간 분량을 받았습니다. 대상일 실측 날씨와 이용자 GPS는 입력에서 제외했습니다. 데이터 제공은 NOAA GFS / Open-Meteo, [CC BY 4.0](https://open-meteo.com/en/licence)입니다. 이 실험은 [비상업 공개 API](https://open-meteo.com/en/terms)를 사용했습니다.

| 같은 28,092개 관측에 적용한 모델 | 실제 승차 인원의 ±20% 이내 | 평균 절대오차 |
|---|---:|---:|
| 현재 운영 모델 | 48.18% (13,535/28,092) | 4.966명/일 |
| 동일 구성 · 날씨 제외 | 47.07% (13,224/28,092) | 4.969명/일 |
| 동일 구성 · 예보 추가 | 47.15% (13,244/28,092) | 4.967명/일 |

기상 입력을 사용하는 후보 15개를 두 시간순 검증 구간에서 비교한 뒤 설정을 고정했습니다. 선정 후보는 현재 예측에 릿지 회귀 보정을 65% 반영하는 구성입니다. 예보를 제외한 비교도 같은 학습 셀·보정 설정을 사용합니다. 시험 120일 전체에 예보를 결합했고, 원래 시험의 250개 통계 코드와 28,092개 관측, ±20% 기준을 유지했습니다. 최종 후보가 보정에 사용한 학습 관측은 예보가 있는 90,760개입니다. 날짜별 예보가 비어 있는 경우를 위해 원래 예측으로 돌아가는 규칙을 정의했습니다.

날씨 입력은 같은 구성의 날씨 제외 모델보다 적중이 20건 늘었지만, 운영 모델의 적중률과 평균오차를 개선하지 못했습니다. 따라서 날씨 후보를 서비스에 적용하지 않았습니다. 이번 결과는 같은 과거 시험 기간을 다시 사용한 제주시 한 기준점의 결과입니다. 지역별 날씨나 실제 운행량을 연결할 경우의 효과는 별도로 검증해야 합니다.

## 재현과 확인 기록

학습 환경에서 `scripts/fetch_jeju_forecast_v22.py`로 예보를 받고 `scripts/experiment_route_weather_v22.py`를 실행합니다. 서비스 내장 런타임은 학습 의존성이나 외부 API 연결 없이 실행됩니다.

```powershell
New-Item -ItemType Directory -Force tmp/weather-v22 | Out-Null
python scripts/fetch_jeju_forecast_v22.py --start 2024-01-01 --end 2025-10-19 --output tmp/weather-v22/archive.json
python scripts/experiment_route_weather_v22.py --weather tmp/weather-v22/archive.json --weather-receipt tmp/weather-v22/archive.receipt.json --output tmp/weather-v22/result
```

이번 예보 응답, SHA-256 확인서, 동결 후보와 평가 기록은 로컬 `development_support/weather_v22/`에 있습니다. 기존 시험 원본, 모델과 학습 환경은 [복원 안내](../GITHUB_RESTORE.md) 및 [승차 추가 실험](모델다양화_v21/승차_추가정보_실험.md)을 참조합니다.
