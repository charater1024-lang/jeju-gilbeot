# 제주 여행 웹사이트 개편과 실제 데이터 연결

개편 완료 기준 2026년 10월 27일. 원자료와 사진은 10월 26일 취득 기록을 보존했다. 기존 13페이지 기획서와 01~06 설계서는 최초 기획 시점의 기록이며, 현재 구현과 자료 확보 상태는 이 문서와 README를 우선한다.

## 달라진 사용 경험

성산일출봉 항공 실사진을 크게 배치한 첫 화면에서 여행을 시작한다. 제주 바다색과 크림색, 작은 귤색 포인트를 사용하고 실제 관광지 사진 카드로 구성했다. 성산일출봉, 협재, 함덕, 한라산, 사려니숲길, 천지연, 정방, 섭지코지, 우도, 오설록 10곳을 소개한다.

지역·키워드 탐색, 관광지 상세와 주소·공식 출처·사진 크레딧, 하트 저장과 브라우저 보관, 실제 저장 장소의 순서 초안을 연결했다. 모바일 메뉴와 카드, 폼, 긴 음식점명 줄바꿈을 확인했다. 사용자 계정·예약·결제 기능은 추가하지 않았다.

## 실제 자료를 사용하는 기능

관광지는 제주관광공사 비짓제주 공식 HTML에서 이름·주소·위경도 등 사실정보를 추출한 참조 자료다. 별도 배포된 공식 CSV를 받았다고 표시하지 않는다. 원본 HTML과 추출 필드, 해시를 data_raw/tourism에 보관한다. 소개는 짧게 새로 작성했고, 사진은 비짓제주 사진을 복제하지 않고 개별 공개 라이선스의 Wikimedia Commons 실사진을 사용했다.

음식점은 허브 원자료 51,111행 중 당시 영업/정상으로 기록된 20,954행을 정리해 검색한다. 장소명·업종·주소와 편집한 방향 분류를 사용한다. 데이터의 최종 행 갱신일은 2025년 9월 2일이다. 이는 모든 점포가 그날 갱신됐거나 현재 영업 중이라는 뜻이 아니다. 음식점 목록은 맛 평점·점포 방문량 순위가 아니다. 좌표가 없어 개별 식당을 실제 이동 경로에 자동 삽입하지 않는다.

## 실제 장소 경로와 머신러닝의 구분

기본 모드는 저장한 실제 관광지의 방문 순서 초안이다. 선택한 장소를 모두 포함해 시간과 추정 이동비 조건을 검사한다. 장소 좌표 사이의 직선거리 보정으로 계산하므로 도로 길찾기가 아니다. 체류시간은 계획용 가정이며 입장료·식사비·주차·렌터카 비용은 확인하지 않아 전체 예산 충족으로 표시하지 않는다.

한라산 대표 좌표는 차량 도착지가 아니므로 탐방로 입구 확보 전 순서 계산에서 제한한다. 우도는 배편이 필요하고 버스는 운행 시간표가 필요하므로 관련 경로를 생성하지 않는다. 이 제한은 승차 통계가 다운로드됐더라도 해제되지 않는다.

합성 자료 ML 추천은 명시적으로 선택하는 개발 체험으로 남겼다. 실제 관광지에 합성 방문량을 붙이지 않는다.

## 실제 카드 자료의 학습 실험

센터 제공 카드 원자료 1048의 내국인·여성 구간을 그대로 선택하고, 8개 업종의 완전한 90개월 계열 720행을 정규화했다. 성별이나 이용자 수를 임의 합산하지 않았다. 관측은 2018년 1월~2025년 6월이며 공간 차원은 제주 전체 집계다. 특정 집단의 과거 소비를 모든 여행자의 선호로 일반화하지 않는다.

모델은 월 계절성과 업종·추세를 사용하는 Ridge 회귀다. 앞 기간으로 학습하고 마지막 18개월의 144행에서 MAE 5,994.36건, WAPE 0.289359를 기록했다. 학습 구간 계절 평균 기준모델은 MAE 6,404.51건, WAPE 0.309158이었다. 이는 한 번의 역사적 검증 실험이며 독립 최종 테스트나 현재 맛집 인기 검증은 아니다.

저장된 전체 이력 모델의 다음 기간 예시는 2025년 7월이다. 현재 시점까지 장기간 외삽한 점수를 여행지·음식점 추천에 적용하지 않는다. 실험 산출물은 models_real_context와 data_reference/real_model_report.json에 있다.

## 다운로드한 자료

| 원자료 | 행 수 | 실제 관측 범위 또는 주요 정보 |
|---|---:|---|
| 음식점 명부 780 | 51,111 | 행 갱신 2018-08-31~2025-09-02 |
| 음식점 인허가 월별 집계 780 | 640 | 인허가월 1960-01~2025-08 |
| 센터 외식업 이용 1047 | 14,832 | 2019-01~2024-12 중 69개월 |
| 센터 카드 이용 1048 | 28,255 | 2018-01~2025-06 90개월 |
| 센터 시간대별 버스 512 | 37,057 | 2023-12-25~2025-10-26 |
| 센터 일별 버스 561 | 14,127,952 | 2019-01-01~2025-10-19 |

CSV 파일은 6개이며 독립 원본 데이터 ID는 5개다. 허브를 통해 받은 센터 제공 자료를 두 번 계산하지 않는다. 약 498MB의 일별 버스 원자료도 로컬 data_raw/hub에 저장한다. 원자료 전체는 실행 ZIP과 분리하며 웹 화면에 원본 파일을 제공하지 않는다. 561은 승차·하차·환승이 혼재하므로 모든 행의 합을 승차 인원이라고 부르지 않는다.

1047의 2023년 9월·11월·12월은 없다. 결측을 0으로 간주하지 않았다. 원본 설명과 실제 CSV의 기간이 다른 항목은 원문과 실제 프로파일을 함께 보존했다. API 기술문서 HWP 8개도 취득했으며 API 응답 원자료가 확보되었다는 의미는 아니다. 743 약 624MB 원본은 이번에 내려받지 않았다.

data_raw/DOWNLOAD_MANIFEST.json에 URL·SHA256·크기·인코딩·열·관측기간과 이용조건 확인 상태를 기록했다. 원본 상세 페이지에는 명시적 라이선스 필드가 없어 연계 메타데이터의 표기와 구분했다. 로컬 분석 파일을 대회 제출·재배포하기 전 제공기관의 현행 이용범위를 확인해야 한다.

사진은 ui/assets, 개별 저작자·라이선스는 docs/PHOTO_CREDITS.md 및 웹 /credits.html에 있다. API Key나 공개 체험용 프로젝트 키는 코드·로그·자료에 포함하지 않았다.

## 실행과 갱신

```powershell
python -m jeju_agent serve
python scripts/prepare_reference_data.py
python -m unittest discover -s tests -v
```

공식 파일 재취득은 `python scripts/download_jeju_data.py`로 별도 refresh 폴더에 저장한다. 기존 자료를 자동으로 덮어쓰거나 서비스에 반영하지 않는다. 원본 ID·첨부·기간·이용조건을 다시 검토한 뒤 교체한다. 대용량 561은 `--ids 561 --include-large`가 있어야 재취득한다.
