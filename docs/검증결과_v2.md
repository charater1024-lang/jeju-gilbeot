# 버전 2 검증 결과

2026년 10월 27일 확인했다.

- 자동 단위 테스트 30개 모두 통과했다.
- 로컬 HTTP 종단간 검사 11개를 통과했다. 실제 관광지 10곳, 실사진 10장 해시, 음식점 지역 검색, 실제 장소 순서, 미확인 가격, 버스·한라산·우도 제한, 최대 방문 수, 잘못된 요청, 정적 파일 접근 경계, 합성 ML 구분을 검사했다.
- 실제 다운로드 원본과 정규화 카드 이용건수 720행을 대조했다. 원본과 모델의 학습 파일 SHA256을 기록했다.
- Chrome에서 관광지 상세, 키워드·지역 검색, 음식점 검색, 하트 저장, 실제 장소 방문 순서와 합성 ML 체험을 확인했다.
- 관광지 실사진 10장이 모두 정상 로드됐다. 모바일 390px에서 본문 너비 375px로 가로 넘침이 없는 상태와 모바일 메뉴를 확인했다. 검증용 화면 크기는 기본값으로 복원했다.
- 긴 음식점명으로 발생한 모바일 가로 넘침을 줄바꿈과 단일 열 목록으로 수정했다.

실제 데이터 학습은 2018년 1월~2025년 6월 내국인·여성 구간의 업종별 이용건수 실험이다. 실제 관광지 경로 초안에는 수요 예측값을 붙이지 않는다. 모델 성능과 비용·경로의 미확인 범위는 07_UI개편과실데이터.md에 기록했다.

검증 명령은 `python -m unittest discover -s tests -v`다. HTTP 검사 산출물은 examples/v2_runtime_smoke.json, 실제 장소 경로 예시는 examples/actual_reference_route.json이다. docs/검증결과.md는 버전 1 기록으로 남겼다.
