# 노선코드별 하루 승차 추가 자료 확인

2026년 11월 6일, 제주데이터허브 공개 메타데이터를 재조회하고 로컬 561 원본의 겹치는 키를 대조했다.

| 자료 | 확인한 범위 | 활용 조건 |
|---|---|---|
| [제주데이터허브 561](https://www.jejudatahub.net/data/view/data/561) | 2019-01-01~2025-10-19, 첨부 5842, 자동 갱신 없음. 원본 열은 날짜·행동 유형·통계 노선코드·이용자 유형·인원 수다. | 이 원본을 기준으로 정한 일반 승차 예측 라벨과 비교 기준을 유지한다. |
| [제주데이터허브 614](https://www.jejudatahub.net/data/view/data/614) | 일일 노선별 API는 날짜 범위, 탑승 구분, 요금제, 지불방법을 받는다. 메타데이터 기간은 2015-01-01로 되어 있으나 공개 미리보기 날짜는 2019-02-01이다. 실제 제공 범위는 발급된 키로 확인해야 한다. | 2019-02-01 `792-5` 일반 카드 승차는 614 미리보기 5명, 561 원본의 일반 승차는 4명이다. 561에는 지불방법 열이 없다. 제공처에 집계 정의와 코드 변천을 확인하고 겹치는 기간을 검증한 뒤 최신 원자료 후보로 평가한다. |
| [제주데이터허브 611](https://www.jejudatahub.net/data/view/data/611)·[612](https://www.jejudatahub.net/data/view/data/612)·[제주버스정보시스템](https://bus.jeju.go.kr/publicTrafficInformation/generalBusSchedule?viewtype=3) | 611 미리보기에는 하위 노선명 `101-1`·`101-2`, 공개 번호 `101`, 각각의 노선 ID와 기종점이 있다. 공식 시간표는 공개 번호와 운행 계획을 제공한다. | 과거 시점별 통계코드 매핑의 유효기간 및 날짜별 계획 운행 횟수를 확보한 뒤 결합한다. 현재 시간표를 과거 날짜에 소급하지 않는다. 실운행 이력과 계획표는 구분한다. |
| [우주항공청·한국천문연구원 2025 월력요항](https://www.kasi.re.kr/publication/post/newsMaterial/30071?cPage=8) | 2024-06-20 발표. 2025년 명절 및 법정 휴일 일정은 시험 시작일 전에 확인할 수 있었다. | 날짜로 결합한다. 임시공휴일·선거일은 예측 기준시각 이전에 확정된 경우에만 사용한다. |
| [기상청 과거 단기예보](https://data.kma.go.kr/data/rmt/rmtList.do?code=420&pgmNo=572)·[기상청 API허브](https://apihub.kma.go.kr/apiList.do?seqApi=10) | 포털은 2010-06~조회일 전일까지의 발표 예보를 제공한다. 2021-06-29 이전은 구 단기예보이며 파일셋 조회 기준시각은 UTC다. 운영 API는 발표시각과 발효시각을 구분한다. | 과거와 운영 모두 동일한 발표 시각의 예보를 사용한다. 예측 대상일의 관측된 비·풍속으로 예보를 대체하면 성능을 과대평가한다. 정류소/노선의 위치 매핑이 없는 동안엔 제주 지역 공통 변수로만 검토할 수 있다. |
| [기상청 ASOS](https://data.kma.go.kr/data/grnd/selectAsosRltmList.do?pgmNo=36&tabNo=2) | 전일 관측자료는 당일 10시 이후 확인할 수 있다고 명시한다. | 전날 밤에 다음 날을 예측할 때는 적어도 예측일 이틀 전까지의 확정 일자료만 검토한다. |
| [국토교통부 시군구별 노선별 평균 이용량](https://www.data.go.kr/data/15162144/fileData.do)·[시군구별 교통수단 이용량](https://www.data.go.kr/catalog/15162136/fileData.json) | 노선별 일평균 자료와 2025년 말까지의 일별 시군구·교통수단 이용량을 각각 제공한다. | 노선코드와 날짜가 함께 있는 동일 정의의 일반 승차 라벨을 대체할 수 없다. |

561과 같은 정의의 최근 일별 승차 실측치는 확인한 공개 파일에서 확보하지 못했다. 과거 관측값을 순차로 사용할 수 있다고 가정한 재현시험과 현재 서비스에서 얻을 수 있는 입력을 구분한다. 시험의 ±20% 기준과 코드 집합을 유지하고, 새 관측이 생기면 공개 시각과 원본 해시를 기록한 뒤 별도 미사용 기간에서 검증한다.
