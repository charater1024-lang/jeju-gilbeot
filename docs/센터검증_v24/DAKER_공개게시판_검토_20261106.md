# 제주 AI·빅데이터 활용 AI Agent 개발 챌린지 공개 게시판 검토

2026년 11월 6일 01:54 KST 전후, DAKER 공개 게시판의 전체·최신순 목록에서 19개 게시물을 각각 열어 최신 본문과 댓글을 확인했다. 운영 공지 1건, 참가자 질문 18건, 운영진 답변 18건(최상위 댓글 17건, 보충 답글 1건)이다. 운영진이 답변한 질문은 17건이다. 충전소 데이터의 개별 인정 문의는 확인 시점에 미답변이었다. 본문은 게시판 주소를 유지한 채 팝업으로 열려 개별 글 주소 대신 아래에 표시 제목과 게시 일시를 기록했다. 댓글 시각은 게시판이 상대 시각으로 표시했다. | 외부 주소와 자료 반출 | 센터 PC는 DLP를 적용한다. 외부 URL 문자열이 차단 키워드에 해당할 수 있으므로 사용하는 주소를 설계서에 적는다. 센터 내부 원본·원본 조회 결과는 외부 LLM 전송에 사용하지 않는다. 집계·가공 결과는 개별 반출 요건을 적용하고, 승인된 자료만 센터 시스템을 통해 반출한다. |

## 제주길벗에 반영할 근거

- **센터에서 쓰는 첫 화면.** 도민 또는 지역 관광사업자가 출발지·방문일·이동수단을 고르면, 한 번의 분석 흐름에서 허브 자료 조회, 실제 장소 기반 후보 생성, ML 판단, 대안과 근거 확인이 이어져야 한다. 단계별로 사용자 입력과 자동 처리 범위를 구분한다. 방문자가 결과를 사업계획서나 현황 자료에 활용할 수 있도록 데이터 기준일·지역 범위·용어와 해석 범위를 붙인다.
- **로컬 실행과 제한된 외부 연결.** 센터의 실행 경로를 Windows의 `127.0.0.1`과 Chrome 또는 Edge 기준으로 문서화한다. 실제 기본 흐름의 외부 호출 수, GPU·키 필요 여부와 반복 실행 지표를 측정한 뒤 제안서에 기록한다. 선택적 지도·원천 링크와 자동 호출을 구분하고, 차단된 상태에서도 조회 가능한 기능을 확인한다.
- **데이터 목록의 경계.** 공개 허브의 사용 데이터별로 이름·출처 URL·관측 기간·전처리·실제 입력 기능을 증빙한다. 대회 전용 목록과 그 변환물의 ZIP·GitHub 포함 여부를 검사한다. 승인과 이용조건을 확인하기 전 센터 방문 자료를 제출물, 외부 서비스 또는 공개 화면에 쓰지 않는다.
- **결과를 검증 가능한 단위로 제시.** 실제 평가 대상 모델별로 평가 기간·표본 수·간단한 기준 모델·오차와 허용 오차 내 비율을 명시한다. 분류 정확도와 회귀 허용 오차 내 비율은 별도 지표로 표현한다. 노선 승차 등 조건을 충족하지 못한 예측은 서비스 기본 판단에 섞지 않고 공식 관측·안내로 분리한다. PDF에 실행 흐름, 재현 명령, 실제 UI와 기능 한계를 담아 상호평가자가 링크 없이 검토할 수 있게 한다.
- **유지보수 주장에 측정값을 연결.** LLM API의 호출 비용과 키 갱신이 없는 구성은 설명할 수 있다. 여러 사용자의 동시 처리 성능은 실제 부하 시험의 요청 수, 오류 수, p95 지연, 장비와 네트워크 조건을 함께 적는다. 센터 실장비와 경쟁 서비스 비교 수치가 없으면 해당 비교를 주장하지 않는다.
