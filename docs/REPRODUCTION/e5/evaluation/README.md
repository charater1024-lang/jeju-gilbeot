# 관광지 의미 검색 독립 평가 동결

2026-11-07. 후보 모델의 출력·점수를 보지 않은 상태에서 실제 검증 소개 62건을 읽고 작성했다. 작성자는 모델 학습·선택 담당과 분리했다.

- `source_partitions.json`: 요청 시점 출처 검사를 통과한 소개 62곳을 고정 ID 해시로 학습 40곳·개발 10곳·holdout 12곳에 나눴다. 소개용 자료 분리이며 자동 코스 자격을 확대하지 않는다.
- `dev_queries.json`: 지원 12개와 미지원 6개. 후보·임계값 선택에 사용할 수 있다.
- `holdout_queries.json`: 지원 24개와 미지원 12개. 후보와 임계값·파일 해시를 동결한 뒤 한 번 평가한다. 결과를 보고 다시 선택하면 새로운 독립 평가라고 주장할 수 없다.
- `protocol.json`, `freeze_receipt.json`: 채택 기준과 원본 파일 SHA-256. 변경하려면 새 프로토콜·새 평가로 구분한다.

지원 질문은 명칭을 직접 묻는 대신 저장한 소개의 내용을 자연어로 바꾼 **개발자 작성 평가 질의**다. 실제 이용자 질문 수집이나 ML 학습 자료가 아니다. 미지원은 현재 운영·요금·허용 조건, 음식 메뉴, 제주 밖 장소, 명부에 근거가 없는 주제, 정보가 부족한 질문을 포함한다. 빈 정답은 이 소개 명부와 조회 기능의 범위 밖이라는 뜻이며 해당 활동·사업체가 실제로 존재하지 않는다고 주장하지 않는다.

동결 정답은 전체 62개 소개를 대조하고 질문의 **모든 식별 사실을 명시적으로 뒷받침하는 문서**를 기준으로 삼았다. 넓은 주제가 비슷하다는 이유만으로 정답을 늘리지 않았다. 각 문항에 실제 소개와 출처 링크를 보존했다. 장소별 두 질문은 서로 상관되어 있으므로 질의 24개를 독립된 이용자 24명의 성과로 표시하면 안 된다. 현장 정확도는 입증하지 않는다.

미지원 문항은 질문이 거짓이라는 판정이 아니다. 영업·현재 요금·장애인 접근 허용·반려동물 조건이나 실제 메뉴를 이 자료만으로 검증할 수 없으므로 장소를 확정 추천하지 않아야 한다. 명확한 지원 밖 안내·추가 질문은 가능하지만 장소 카드가 나오면 이 안전 지표에서는 실패로 센다.

fine-tune에는 `partition=train`의 실제 이름-소개 쌍만 사용할 수 있다. 검색 시 모든 검증 문서를 인덱싱하는 것은 허용한다. 이는 corpus retrieval이며 holdout 질문과 정답을 gradient update·threshold 선택에 사용하는 것과 구별한다. legacy 정확한 명칭·출처·미지원 회귀도 함께 검사하되 기존 고정 질문의 통과 수를 새 모델의 사용자 정확도로 표시하지 않는다.

평가는 `Hit@1`, `Hit@3`, `Recall@3`, `MRR@3`, 미지원 장소 추천 수를 함께 보고한다. 현재 각 문항의 관련 문서가 하나여서 Hit@3과 Recall@3은 같지만 지표 정의는 프로토콜에 따로 기록했다. GPU·CPU 지연시간과 센터 PC의 현장 성능도 구분한다.
