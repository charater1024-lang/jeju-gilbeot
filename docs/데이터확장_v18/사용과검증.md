# 제주 길벗 데이터·모델 확장 v18

2026년 11월 4일. 기존 프로젝트 폴더에 실제 원자료를 학습한 모델 2종과 여행자료 검색 모델을 추가했습니다. 내장 Python과 로컬 CPU로 실행하며 런타임 LLM·외부 모델 API·GPU를 요구하지 않습니다.

## 화면에서 사용하는 방법

`run_center.cmd`를 실행한 뒤 `http://127.0.0.1:8765/explore#data-guide`를 엽니다. ‘여행 전에, 데이터로 한 번 더.’에서 자료 유형을 고르고 비교합니다. 화면의 날짜는 KST 기준입니다.

- 버스 노선 이용 경향. 비워 두면 최근 기록이 충분한 주요 통계 코드를 비교합니다. 특정 코드는 `202-14`처럼 원자료 코드 그대로 입력합니다. 날짜의 요일을 학습 패턴에 적용하며, 현재 운행 노선으로 연결한 결과가 아닙니다.
- 세부 외식업종. 월을 선택하고 `한식`처럼 중·소분류를 부분 검색합니다. 업종별 구성비·평가 평균오차·과거 결제 건당 금액을 함께 표시합니다. 검색 후에도 구성비 분모는 94개 학습 업종 전체로 유지합니다.
- 걷기 코스. 제공 소요시간 상한으로 필터합니다. 시간이 없는 숲길은 시간 제한 검색에서 제외합니다. 올레 제공시간은 해당 구간에 한정하며 출발지 이동·복귀·배편을 포함하지 않습니다.
- 해변 편의시설. `협재` 또는 `화장실 주차장 있는 해수욕장`으로 실제 기록을 비교합니다.
- 접근성 참고. `한라수목원` 등의 명부와 위치를 검색합니다. 2021년 무장애 명부 수록은 현재 구간 접근성 확인과 구분합니다.
- 주변 편의시설. `공영주차장`, `전기차충전소` 등을 검색하고 기준일·주소·원문을 확인합니다. 명칭이 없는 원문은 명칭 미기재로 표시합니다.

한 문장 도우미에도 `6월 세부 외식업종 비교`, `6월 한식 세부 외식업종 비교`, `노선별 하루 승차 수요 비교`, `해수욕장 편의시설 비교`를 연결했습니다. 복수 월·요일·노선, 연도 지정, 미지원 집단·시간대, 부정·복합 일정 조건은 계산을 진행하지 않고 입력을 확인합니다. 기존 일정 상태는 유지합니다.

복잡한 노선 회귀 후보도 학습·평가했으나 검증에서 요일 모델보다 오차가 커 운영에 채택하지 않았습니다. 모든 모델 선택은 검증 구간에서 끝내고 테스트 결과로 재튜닝하지 않았습니다. 노선은 730일 적합 구간과 이후120일 검증·120일 테스트를 고정했습니다. 외식은 2019~2021년 적합·2022년 검증을 거쳐, 모든 비교 모델을 같은 2019~2022년48개월로 재적합한 뒤 2023~2024년 실제 관측21개월을 평가했습니다. 외식 누락 월2023-09·11·12와 누락 셀은 0으로 채우지 않았습니다. 평가는 과거 기록의 후향평가이며 새로운 현장 이용자 정확도가 아닙니다. 평가 후 운영 모델은 선정된 설정으로 최신 보관 관측에 재적합했습니다.

1퍼센트포인트(pp)는 비중30%와31%의 차이입니다. 회귀 모델에는 accuracy 대신 평균오차와 명시한 허용오차 내 비율을 사용합니다. 결제 건당 금액은 2024년 관측 이용금액÷이용건수이며 예측한 메뉴 가격이나 1인 식사비가 아닙니다.

## 검증과 재현

Python 279개, UI 18개 파일, JavaScript 문법 10개 파일, 실제 로컬 HTTP 32건을 통과했습니다. Chrome에서 여섯 가지 자료 비교·검색 흐름과 화면 배치를 확인했습니다. 브라우저 점검 중 실제 GPS 권한은 사용하지 않았습니다. 센터 최소사양 실측과 모바일 화면 검수는 남아 있습니다.

전체검사는 `runtime/python.exe dev.py test`, 무결성검사는 `runtime/python.exe dev.py check`입니다. 각 모델은 `scripts/train_route_demand.py`, `scripts/train_dining.py`, 여행자료는 `scripts/build_travel_context.py`로 재현합니다. 기본 실행에 재학습은 필요하지 않습니다. 노선 모델은 모델·평가·선정 명세 SHA256와 계수 형식을 검증하고, 외식 모델은 계수·원자료 해시를 검증합니다. 여행자료는 원본과 학습 산출물 해시를 확인합니다.

상세 근거는 [노선 모델 보고서](노선수요_모델보고.md), [외식 모델 보고서](외식세분화_모델보고.md), [여행자료 보고서](여행정보_데이터보고.md), [검증 결과](검증결과_v18.json), [성능 수치](성능요약.json)에 있습니다. 기존 정식 제안서는 작성 시점v16 문서입니다. v18 구현 설명은 이 보고서를 기준으로 확인할 수 있습니다.
