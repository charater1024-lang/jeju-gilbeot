# 여행 정보 데이터 확장 결과

2026년 11월 4일. 실제 공개 원본을 내려받아 보관하고, 2,650개 자료 기록으로 문자 2·3-gram TF-IDF 검색 모델을 적합했다. 서버 실행에는 네트워크·GPU·LLM·API 키가 필요 없다. 이 모델은 자료 검색과 비교를 지원하며 현재 접근성이나 개인의 여행 만족도를 예측하는 모델이 아니다.

## 확보한 실제 원자료

858의120행은120개 고유 관광지를 뜻하지 않는다. 한림공원처럼 같은 이름에 다른 주소·좌표가 있는 기록은 하나로 임의 병합하지 않는다. 871의 현재 메타데이터는 완전한CSV 대신 API 안내와 미리보기 파일을 제공한다. 따라서 다운로드한19코스만 부분 자료로 명시했다. 일부 코스의 '휠체어 구간 있음'은 전 구간 통행 가능을 뜻하지 않는다.

허브497은 실제 연결된 공공데이터포털에서 최신 원본을 받았다. 허브에 보이는2016년 미리보기를2025년 자료로 바꾸어 표시하지 않았다. 실제2025년CSV와 양쪽 메타데이터를 함께 보존했다. 페이지 수정일은 시설 현장 확인일로 사용하지 않는다.

## 서비스 연결 계약

`jeju_agent.travel_context.search_travel_context(root, *, kind='walk', query='', max_minutes=None, limit=8)`을 사용한다. kind는walk·beach·accessible·amenity다. 결과의items에는 이름, 한글key의known, 원문행evidence, 출처, 자료기준일, 미확인항목unknown이 있다. 모든 결과의route_eligible와automatic_eligible은false다.

- '송악산'은2025년 숲길CSV의1.2km 기록을 찾는다. 좌표를 만들어 넣지 않는다.
- '2시간 안에 걷기 코스'는871의 제공 소요시간 상한이120분 이내인 수록 구간만 찾는다. 소요시간이 없는 숲길은 이 조건에서 제외한다. 수록된 가파도 구간의1~2시간은 출발지 이동·복귀·배편을 포함하지 않는다.
- '화장실 주차장 있는 해수욕장'은2023년 시설 수와 주차 규모가0보다 큰 자료만 찾는다. 실시간 잔여 주차면이나 현재 시설 운영을 답하지 않는다.
- 무장애 검색 결과는2021년 명부 수록 사실을 표시한다. 현재 휠체어·유모차 통행이나 출입구·경사·시설 상태를 확정하지 않는다.
- 마을편의시설은 원문에 당시 운영시간·영업상태가 있어도 현재 사실로 승격하지 않는다. 현시점 운영·통제·근처 순서 요청과 미지원 부정·최소시간 조건은unsupported로 반환한다.

## 학습과 평가

명칭·주소·실제 분류·거리 등의 제공 필드로 학습 문서를 구성했다. 실제2,650문서의 문서빈도에서24,562개2·3-gram의IDF를 학습하고, TF-IDF cosine 유사도로 근거가 있는 기록을 정렬한다. 이름·지역·시설 조건은 원문 단어가 모두 일치해야 하며, 시간·시설 조건은 실제 필드로 별도 검사한다. 인위적 관광지나 만족도 라벨을 만들지 않았다.

이 검색에는 실제 이용자 관련성 정답이 없어 accuracy를 산출하지 않았다. 기능 회귀검사7개 통과는 검색 정확도가 아니다. 별도 사용자 질의·관련 기록 정답을 수집한 뒤Recall@k·Precision@k를 평가할 수 있다. 날짜·소요시간·시설 조건 및 원자료 해시를 검사했고 원자료 변경 시 재구축이 실패하도록 했다. 빌드 결과 해시가 달라지면 런타임 검색도 중단한다.
