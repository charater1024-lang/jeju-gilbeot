# 실행과 데이터 연결 매뉴얼

## 현재 시제품 시작

Python 3.10 이상에서 프로젝트 폴더를 터미널의 작업 위치로 설정한다. `python -m jeju_agent serve` 실행 후 브라우저에서 `http://127.0.0.1:8765`에 접속한다. 키·회원가입·pip 설치는 없다. 서버는 로컬 주소만 사용한다. 기본 모델이 없으면 동봉 자료로 학습한 뒤 시작한다.

Windows에서는 프로젝트 폴더의 `run_demo.ps1`을 사용할 수 있다. Python 설치가 Microsoft Store 별칭만 남아 있다면 이 PC의 Codex 번들 Python을 찾는다. 다른 PC에서는 Python 3.10 이상을 설치하고 명령으로 실행한다. 스크립트 정책을 변경할 필요는 없다.

종료는 터미널 Ctrl+C다. 8765 포트가 사용 중이면 `python -m jeju_agent serve --port 8766`을 쓰고 해당 포트에 접속한다. 서버를 인터넷에 공개하지 않는다.

## 학습과 예측

```powershell
python -m jeju_agent validate
python -m jeju_agent train
python -m jeju_agent recommend --request examples/request.json
python -m jeju_agent train-context --csv examples/region_demand_example.csv
python -m jeju_agent forecast-context --month 2026-01
python -m unittest discover -s tests -v
```

장소 모델은 `models/model.json`, `models/metrics.json`을 쓴다. 지역 모델은 `models/model_context.json`, `models/metrics_context.json`으로 분리한다. 지역 모델 예시는 2023년 1월~2025년 12월의 합성 관측이다. 예시의 다음 달인 2026년 1월을 예측한다. 실제 서비스는 확보한 자료의 최종 관측월과 공개 지연을 기준으로 예측월을 설정한다.

장소 모델에는 학습 CSV 해시를 저장한다. 파일을 수정했다면 같은 데이터로 다시 학습해야 한다. 추천 날짜는 장소 모델의 학습 종료일보다 이후여야 한다. 데모 기본값은 2026년 10월 27일이다.

## 실제 지역 집계 반입

1. 공공데이터포털과 허브에서 기술문서·CSV 또는 API 응답을 적법하게 확보한다. 현재 코드에는 추측한 API 엔드포인트를 넣지 않았다.
2. 실제 열을 `month,region,category,value,measure,source_id`로 변환한다. 이용 건수는 transactions로, 금액은 amount_krw로 표현한다. 한 학습 파일에는 같은 측정값만 담는다.
3. 합산 가능한 집계 차원인지 코드북으로 확인한다. 누락·비공개·이용자 중복은 별도 처리한다. 반복 집계키는 오류로 취급한다.
4. `python -m jeju_agent train-context --csv data_real/region_demand.csv --models models_real`로 학습한다.
5. `python -m jeju_agent forecast-context --models models_real --month YYYY-MM`로 미래 월을 예측한다. 해당 값은 지역·업종 맥락이며 개별 식당의 방문량이 아니다.
6. 지역 점수를 장소 추천으로 결합하는 운영형 계층을 추가하고 실제 데이터로 경로 평가를 수행한다. 현재 UI는 장소 합성 엔진에 연결되어 있다.

지역 학습 모듈의 provenance는 source_id에 따른 선언 상태일 뿐 원 제공기관이 확인한 이용 승인 증거가 아니다. 원본 해시·출처·이용조건을 별도 manifest로 보관한다.

## 점포별 방문 자료가 확보된 경우

`examples/source_manifest.template.json`을 복사해 실제 출처로 채우고 표준 `pois.csv`, `demand.csv`와 같은 폴더에 둔다. 템플릿의 pending 값을 approved로 바꾸는 것은 제공기관의 승인을 대체하지 않는다. 실제 확인한 근거를 적어야 한다.

```powershell
python -m jeju_agent validate --data data_staging --real
python -m jeju_agent import --data data_staging --target data_real
python -m jeju_agent train --data data_real --models models_real --real
python -m jeju_agent serve --data data_real --models models_real
```

이 반입 기능은 원자료 재배포 허용 자료만 지원하는 보수적인 예시다. 센터 내부 학습만 허용되는 자료는 이 기능으로 패키지에 복사하지 않는다. 센터 내부 실행·모델 반출 절차를 별도로 만든다. 두 플랫폼 조건은 이 프로젝트가 정한 완료 기준이며 대회 공식 최소 조건과 다르다. 동일 원본을 다른 플랫폼 이름으로 중복 등록하지 않는다.

엔진은 진위가 검증된 관측임을 자체 인증하지 않으며 사용자 반입 자료도 unverified로 반환한다. 실제 서비스 승인은 출처 검토·모델 검증·지역과 점포 관측 단위 검증을 마친 뒤 별도 관리해야 한다.

## 오류 대응

| 증상 | 원인과 조치 |
|---|---|
| python 실행 불가 | Python 3.10 이상 설치 또는 run_demo.ps1의 번들 경로 확인 |
| 모듈 없음 | 프로젝트 루트에서 실행하고 jeju_agent 폴더 확인 |
| 학습 이력 부족 | 최소 기간을 확보하고 일별/월별 단위를 바꾸지 않음 |
| CSV 누락·필드 오류 | 원본의 인코딩·열 매핑·숫자·식별자 점검 |
| 해시 불일치 | 수정한 데이터로 재학습, 기존 모델 재사용 금지 |
| 과거 날짜 거절 | 학습 종료일 이후 선택, 과거 성능은 시간 분할로 평가 |
| 경로 불가능 | 시간·예산·지역 범위 조정, 오류를 빈 성공으로 취급하지 않음 |
| 버스 unsupported | 시간표 미연결 정상 제한, 교통수단을 사용자가 변경 |
| 실데이터 반입 거절 | 실제 출처·권한·측정단위와 플랫폼 메타데이터 점검 |

## 운영형 추가 작업

실제 지역 모델과 UI 경로의 결합, 음식점 좌표·영업·가격 보완, 버스 운행 그래프, 데이터 탐색 도구, 통합 에이전트 재계획, 비전문가 보고서 내보내기는 후속 구현이다. 원본과 API Key는 저장소·화면·ZIP에서 제외하고 데이터 관측시각과 한계는 결과에 표시한다.
