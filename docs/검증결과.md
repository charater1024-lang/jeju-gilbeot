# 실행 검증 결과

확인일 2026년 10월 26일. 이 문서는 실제로 실행한 항목과 그 범위를 기록한다.

## 확인한 결과

- Python 3.12.14에서 표준 라이브러리 실행 확인
- 전체 단위 테스트 25개 통과: 데이터 누수·입력·모델 손상·출처 계보·시간·비용·귀환·버스 제한
- 로컬 HTTP 스모크 검사 9개 통과: 상태·카탈로그·자동차·예산/복귀·6단계 기록·버스 제한·도보·잘못된 예산·과거 날짜
- Chrome 실제 화면에서 자동차 추천 생성, 버스 자료 부족 안내, 비용과 예상 복귀시각 표시 확인
- PDF 13페이지 전체를 PNG로 렌더링해 한글·표·겹침·잘림 시각 검수 통과
- 모델과 CSV 해시 연결, 합성 출처 표시, 동일 원본 중복 등록 거절 확인

## 합성 예시 경로

examples/request.json의 조건에서 방문 5곳, 예상 비용 59,851원, 총 이동 195분, 예상 복귀 17시 55분을 반환했다. 예산 100,000원과 마감 18시 조건을 만족했다. 이는 합성 장소와 가정한 이동시간/비용으로 계산한 결과다. 실제 제주 여행 실행 가능성의 검증이 아니다.

## 합성 학습 결과

| 모델 | 검증 구간 | 모델 MAE | 기준모델 MAE |
|---|---|---|---|
| 장소 일수요 | 2026-09-20~2026-10-25 | 11.895 | 장소 평균 21.981 |
| 지역 월수요 | 2025-05~2025-12 | 17.018961 | 학습 구간 계절 평균 94.484375 |

모든 수치는 합성 자료에서 계산했다. 실제 데이터 성능, 개인화 정확도, 맛집 품질 또는 대회 점수를 의미하지 않는다. 월별 예측의 다음 달 예시는 2026년 1월이다.

## 재현 명령

```powershell
python -m unittest discover -s tests -v
python -m jeju_agent validate
python -m jeju_agent train
python -m jeju_agent recommend --request examples/request.json
python -m jeju_agent train-context
python -m jeju_agent forecast-context --month 2026-01
python -m jeju_agent serve
```

## 아직 검증하지 않은 항목

제주 원자료 취득과 이용 승인, 실제 수요 모델의 독립 테스트, 실제 도로망과 버스 운행 가능성, 점포별 인기와 방문 전이, 센터와 동일한 사양의 성능, 비전문가 사용자 실험은 수행하지 않았다. 현재 6개 실행 단계에는 자율 도구 선택·재계획·독립 LLM 협상이 없다. 지역 월별 예측을 UI 경로 엔진과 결합하는 운영형 계층도 후속 작업이다.

docs/시제품화면.png는 로컬 화면 검증 시 저장한 결과다. 실제 자료 연결 상태는 미확보로 표시했다.
