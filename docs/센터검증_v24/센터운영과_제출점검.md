# 제주 길벗 v24 센터 운영과 제출 점검

2026년 11월 6일 확인. [공식 대회 안내](https://daker.ai/public/hackathons/jeju-ai-bigdata-agent-challenge)와 [DAKER 공개 게시판](https://daker.ai/public/hackathons/jeju-ai-bigdata-agent-challenge?section=board)을 기준으로 작성했다. 글별 질문과 답변은 [19건 검토 기록](DAKER_공개게시판_검토_20261106.md)에 있다. 충전소 자료의 개별 인정 문의는 확인 시점에 답변이 없었으며, 이 프로젝트의 필수 데이터 사용 근거로 삼지 않는다.

## 같은 PC에서 체험하기

1. 센터에서 승인된 Windows 폴더에 패키지를 풀고 `run_center.cmd`를 실행한다. Chrome 또는 Edge에서 [로컬 첫 화면](http://127.0.0.1:8765/)을 연다. 실행 창을 닫으면 서버가 종료된다. 기본 실행은 다른 PC에 서버를 공개하지 않는다.
2. 홈의 **센터 PC 체험 안내** → **로컬 실행과 인터넷 연결 범위** → **실행 상태 확인**을 누른다. 로컬 응답과 운영 모델 3종의 평가 정보가 확인되어야 한다. 문제가 있으면 실행 창의 오류와 동일 PC에서 열린 로컬 주소를 먼저 확인한다.
3. **공식 소개 검색**으로 관광지 설명의 출처와 확인일을 살펴본다. **자료 비교**에서는 관심 월의 외식업종 구성비와 과거 평가 오차를 함께 확인한다. 구성비 추정은 현재 영업 여부나 특정 음식점의 순위를 뜻하지 않는다.
4. **일정 조건 입력** → **예시 조건 채우기** → **제주공항 출발로 확인** → **코스 만들기** 순으로 실행한다. 예시는 자동차로 북부 3곳, 09:00~18:00, 추정 이동비 한도 10만원이다. 공개 기준점을 직접 확인해야 하며 센터 PC 위치는 자동 적용하지 않는다. 결과에서 도로 참고 경로, 돌아오는 시간, 장소별 출처를 본다. 이동비에 입장·식사·주차 등은 포함하지 않으며 영업·입구·방문 가격은 출발 전 확인한다.
5. 사용을 마치면 파일 집계를 지우거나 **새 여행 시작**으로 화면을 초기화한다. 센터 운영 기준에 따라 사용자가 내려받은 파일과 일정 내보내기 파일도 별도로 관리한다. 앱의 초기화는 PC에 따로 내려받은 원본을 삭제하지 않는다.

## 내려받은 CSV에서 관측값 확인

게시판에서 운영진이 안내한 센터 자료 취득 방식은 사용자 승인 범위에서 CSV로 내려받는 것이다. 제주 길벗은 직접 DB/API 연결을 사용하지 않는다. 체험 화면의 **내려받은 1048 CSV로 실제 이용건수 비교**는 공개 [제주데이터허브 1048](https://www.jejudatahub.net/data/view/data/1048) 형식에 한해 제공한다. 임의의 센터 CSV를 받는 기능은 아니다.

| 항목 | 동작 |
| --- | --- |
| 파일 | CSV 헤더 `base_year_month`, `biz_nm`, `user_type`, `sex`, `use_count`. UTF-8 또는 지원되는 한글 CSV 인코딩, 최대 8MiB. |
| 집계 | 한 월과 원자료의 `제주도민` 또는 `내국인`을 선택해 8업종 이용건수와 구성비를 확인한다. 필요한 관측치가 빠진 집계를 0으로 채우지 않는다. |
| 데이터 처리 | 선택한 파일을 탭의 메모리에서 읽고 집계한다. 서버 업로드, 브라우저 영구 저장, 운영 모델 재학습은 하지 않는다. 파일의 이용 승인과 출처 확인은 별도다. |
| 확인 기준 | 실제 1048 원본에서 2025년 6월 제주도민 8업종 이용건수 합계 785,479건을 브라우저에서 확인했다. **선택 파일과 결과 지우기**로 표가 비워지는 것도 확인했다. |

## 설치와 연결 범위

| 항목 | 필요한 것 |
| --- | --- |
| 기본 실행 | 동봉 Windows Python, 로컬 데이터·모델과 브라우저. 외부 로그인, API 키, GPU 추론, pip 설치 없이 실행한다. 앱은 같은 PC의 루프백 주소로 연결된다. |
| 이용자가 켜는 온라인 지도 | `https://tile.openstreetmap.org/{z}/{x}/{y}.png`. 접속이 차단되거나 지연되면 로컬 지도를 표시한다. OSM 저작자 표시와 [데이터 이용조건](https://www.openstreetmap.org/copyright)을 유지한다. |
| 이용자가 여는 원문 | 제주데이터허브(`www.jejudatahub.net`), 공식 관광 원문 등 장소마다 표시된 출처, 선택형 OSM 주소 검색(`www.openstreetmap.org`). 센터에 외부 접속이 필요한 경우 제출 설계서에 실제 목적지를 적는다. |
| 개발·검증 | 개발 시 Codex를 활용했다. 런타임은 외부 LLM에 입력이나 데이터를 보내지 않는다. 운영 ML은 1048 소비 구성비, 1047 외식 구성비, 공식 관광 소개 문서 검색에 사용한다. 출발 확인·장소 선별·시간과 이동비 확인은 규칙과 경로 계산으로 처리한다. [운영 모델과 오차](../운영모델_v23.md) |

전체 이전본에서는 `runtime\python.exe -B dev.py check`로 파일 해시를 점검한다. 이 해시 목록은 개발 이전본용이며 최종 ZIP 파일 목록과 구분한다. 개발 노트북에서 Python 검사 301건, UI 검사 19건, JavaScript 구문 확인 13건이 통과했다. 브라우저에서 로컬 실행 확인·1048 원본 집계·파일 지우기·미확인 출발 차단·공항 확인 후 3곳 추천을 확인했다. [동시 요청 측정과 범위](동시요청_검증.md)에서 로컬 서버 결과를 확인할 수 있다. 실제 센터 PC의 설치·화면·응답시간·공용 브라우저 초기화는 탑재 시 확인한다.

## 제출 전에 할 일

- [공식 대회 안내](https://daker.ai/public/hackathons/jeju-ai-bigdata-agent-challenge)에 따라 **2026년 11월 20일 10:00 KST**까지 기획서 PDF(15쪽 이내)와 최종 ZIP을 갤러리에 제출한다. 상호평가는 PDF 기준이며 전문가 심사에서는 ZIP으로 실제 실행을 확인할 수 있다. 선택 링크로 실행 파일을 대신하지 않는다.
- 최종 ZIP에는 실행 소스, 실행 환경과 매뉴얼, 데이터 활용 명세, 결과 설명자료를 담는다. 승인된 제출 파일만 새 폴더에 꾸린 뒤 별도 Windows 환경에서 실행해 본다. 개발 이전 폴더나 그 해시 목록 전체를 ZIP으로 내지 않는다.
- 제주데이터허브 공개 자료와 대회가 별도로 제공한 원본을 구분한다. 별도 목록의 대회 제공 원본과 이를 담은 DB를 ZIP과 GitHub에서 제외한다. 공개 자료와 가공본도 각각 이용조건을 확인한다. 센터 자료는 지정된 승인 절차를 따른다. [데이터 출처와 내려받기 기록](../데이터다운로드보고.md), [사진 출처](../PHOTO_CREDITS.md), 동봉된 외부 코드 및 데이터의 출처·라이선스를 유지한다.
- 센터의 반출, 외부 접속, 제출 파일 이용에 관한 조건은 제출 직전 최종 운영 안내와 동의문을 함께 확인한다. 이 문서는 11월 6일 공개 안내에 근거한 작업 기록이며, 실제 제출이나 센터 설치 완료를 뜻하지 않는다.
