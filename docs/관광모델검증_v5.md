# 관광 검색 모델 검증 v5

관광 검색은 실제 명칭과 관측 분류의 TF-IDF 표현을 학습한 비지도 검색입니다. 점포나 관광지의 인기, 만족도, 방문량을 예측하지 않습니다.

## 학습 자료

학습 문서 6,529개 중 기본 관광·자연 기록은 1,148개, 별도 여행장소 참조 명부는 5,381개입니다. 출처별 기록 수이며 고유 관광지 수가 아닙니다.

어휘 14,398개와 희소 가중치 113,272개를 학습했습니다. IDF는 log((1+문서 수)/(1+문서 빈도))+1로 계산하고 문서 벡터를 L2 정규화했습니다.

학습에는 이름, 알려진 분류, 주소, 실제 OSM 분류 태그와 있는 원문 설명만 사용합니다. 공식 참조 카드의 편집 태그와 편집 소개문은 관측 설명으로 학습하지 않습니다.

## 검증 범위

기본 attraction과 분류 미확인 reference를 분리하고, OSM 숙박 태그와 잘못된 좌표를 제외합니다. 동일 장소의 출처 간 강제 병합은 하지 않습니다. 문자 관련도는 추천 정확도 평가가 아니며 라벨이 있는 사용자 선호 검증은 아직 없습니다.

검색은 지역·분류·지도 범위·테마·선택적 위치를 지원합니다. 원시 GPS를 로그나 파일에 남기거나 응답 및 cursor에 넣지 않습니다. cursor는 공개 모델 버전과 다음 offset만 포함합니다.

## 과거 집계 모델 비교

| 모델 | 서비스 선택 | 검증 및 테스트 근거 |
|---|---|---|
| 집단 소비 | audience_mean | 테스트 구성비 MAE 실험 0.01601372, 평균 기준 0.01593516 |
| 승차 시간대 | weekday_bucket_mean | 테스트 시간당 MAE 실험 109.9577, 평균 기준 86.4884 |

선택은 각 모델의 기존 검증 구간 오차를 기준으로 했으며 기존 테스트를 재탐색하지 않았습니다. 관광 TF-IDF의 성능으로 위 집계 모델 수치를 제시하면 안 됩니다.

## 출처와 제한

- 문자 표현을 학습한 비지도 검색 모델입니다. 인기·만족도·방문량·개인 선호 정답을 예측하지 않습니다.
- 기록 수는 출처별 행 수이며 서로 다른 출처가 같은 장소를 가리킬 수 있습니다. 고유 관광지 수로 해석하지 마세요.
- 기본 관광·자연 공개기록과 허브 여행장소 참조 명부를 분리했습니다. reference 명부를 관광지 확정 통계에 섞지 않습니다.
- OSM 원문 분류에서 숙박 태그를 제외했습니다. 남은 자연·여가 기록이 공식 승인 관광지라는 뜻은 아닙니다.
- OSM 개별 편집일과 데이터베이스 스냅샷 시각은 서로 다르며 현재 영업·개방·접근성을 검증한 날짜가 아닙니다.
