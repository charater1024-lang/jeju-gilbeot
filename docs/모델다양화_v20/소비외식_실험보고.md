# 소비·외식 모델 학습 조합 다양화 결과

2026년 11월 4일. 실제1048·1047 원자료에서 총956개 후보를 비교했습니다. 고정된 허용오차 기준93%를 두 모델 모두 달성하지 못했으며, 기존 운영 모델보다 악화된 후보는 적용하지 않았습니다.

## 평가 전에 고정한 범위

- 1048은 기존8업종×2집단과 ±1퍼센트포인트 기준을 유지했습니다. 평가기간은2024-01~2025-06의288개 셀입니다.
- 1047은 기존94개 완전 관측 업종과 ±0.25퍼센트포인트 기준을 유지했습니다.2023-01~2024-12 중 실제21개월·1,974개 셀입니다. 누락3개월을0으로 채우지 않았습니다.
- 1048 검증은2022년 하반기·2023년 상반기·2023년 하반기 각6개월을 사용했습니다. 각 검증 시작 전까지의 관측만 학습했습니다.
- 1047 검증은2021년 하반기·2022년 상반기·2022년 하반기 각6개월입니다. 실제 테스트 관측은 후보 선택에 사용하지 않았습니다.
- 후보 목록·검증기간·고정 허용오차·선정 규칙을 검증 전에 명세에 저장했습니다. 허용오차 내 비율을 우선하고 검증 MAE가 비교기보다2%를 넘게 악화하면 후보에서 제외했습니다. 선정 후 실제 운영 모델과 같은 적합범위의 비교와 추가 검증 MAE guard도 확인했습니다.
- 운영 교체는 고정 테스트에서 허용오차 내 비율이 높아지고 MAE가 악화되지 않은 경우만 허용했습니다. 테스트를 본 뒤 다른 후보를 다시 선택하지 않았습니다.

기존 공개 평가기간을 다시 사용하는 후향 비교입니다. 새 관측기간이나 새 실제 이용자에 대한 독립 성능 보장이 아닙니다. 데이터의 최신 공개기간도1048은2025년6월,1047은2024년12월로 확인됐습니다.

1047의 선정 후보는 검증에서는93.50%였지만 고정 테스트에서는90.07%였습니다. 검증의93%를 서비스의93% 달성으로 표시하지 않았습니다. 1048 선정 후보도87.15%로 기존87.50%를 넘지 못했습니다. 두 후보의 추가 실제 운영 비교기 검증 MAE guard는 통과했으나 테스트 교체 기준은 통과하지 못했습니다.

복잡한 모델이 최근 가중 평균보다 시계열 검증에서 항상 나은 것은 아닙니다. 월만으로 추론하는 현재 서비스 범위에서는 관측 후의 소비 구조 변화와 작은 업종의 변동을 모든 연도에 맞추기 어렵습니다. 이 결과를 근거로 같은 테스트를 다시 보며 조합을 추가 튜닝하지 않았습니다.

## 비교기 점검과 교정 기록

초기c000 Ridge 참고 후보는 학습 가중치의 합을 표본수로 정규화합니다. 기존 운영 Ridge는 가중치를 정규화하지 않아 같은 alpha 숫자라도 정규화 강도가 다릅니다. 초기 참고 후보를 그대로 기존 운영 모델이라고 표시할 수 없어, 별도 교정 단계에서 실제 기존 모듈의 적합 함수를 호출해 동일 학습기간의 검증·테스트 수치를 다시 계산했습니다.

최초 선정 후보ID와 설정은 바꾸지 않았습니다. 선택이 끝난 후 실제 운영 비교기 guard를 추가 적용했고, 다른 후보를 새로 선택하지 않았습니다. 초기 고정 명세·초기 비교·교정 명세를 모두 보존했습니다. 교정한 기존 모델 수치는1048 MAE0.42611054pp/87.50%,1047 MAE0.09719669pp/90.6788%로 기존 보고서와 일치합니다.
