# 제주 공개 원자료 다운로드 결과

취득일은 2026년 10월 26일이다. 제주데이터허브의 정상 공개 파일 주소에서 CSV 원본 6개와 API 기술문서 HWP 8개를 다운로드했다. CSV는 모두 HTML 차단 페이지가 아닌 비어 있지 않은 표 데이터로 검증했으며 원본 바이트는 변경하지 않았다. 6개 CSV는 원본 데이터셋 식별자 5개에 속한다. 음식점 명부와 해당 명부의 인허가 월별 집계는 동일한 780번 데이터셋이므로 두 독립 원자료로 세지 않는다.

파일별 원문 URL, 다운로드 시각, 바이트 수, SHA256, 행 수, 인코딩, 전체 열 이름, 관측 기간 및 이용조건 상태는 [manifest.json](manifest.json)에 기록했다. 실제 CSV 총량은 511,648,389바이트이며 메타데이터·HWP·인코딩 변환본은 여기에 포함하지 않는다.

## 웹사이트 연결 시 사용할 실제 필드

### 음식점 명부 780

사업장명, 업종구분대분류, 업종구분소분류, 인허가일자, 인허가취소일자, 영업상태명, 상세영업상태명, 폐업일자, 휴업시작일자, 휴업종료일자, 재개업일자, 소재지면적, 소재지전체주소, 도로명전체주소, 도로명우편번호, 데이터갱신일자.

- `영업상태명 == 영업/정상`은 20,954행, `폐업`은 30,157행이다.
- 일반음식점은 37,960행, 휴게음식점은 13,151행이다. 이 숫자는 폐업 자료를 포함한 전체 명부의 분류별 행 수다.
- 주소는 도로명전체주소를 우선하고 비어 있으면 소재지전체주소를 사용한다.
- 위경도·방문자 수·평점·메뉴 가격·현재 영업시간 필드가 없다. 주소만으로 임의 좌표를 생성하거나 명부에 있는 음식점을 인기 맛집이라고 표시하지 않는다.
- 최신 갱신일이 2025년 9월 2일인 명부다. `영업/정상`은 그 스냅샷의 상태이며 방문 당일 영업을 보장하지 않는다.
- `jeju_food_registry_780.utf8.csv`는 편의를 위한 UTF8 BOM 파생본이다. 원본은 `jeju_food_registry_780.csv`이며 그 SHA256은 `e96e47b9932e3f3559ec843155cf0ac67f6149e895732a5247078d777deb1dcc`다. 최초 확보 과정의 `jeju_food_registry_780.raw` 및 `.csv`는 같은 바이트의 별칭이므로 중복 취득으로 계산하지 않는다.

### 센터 외식업 집계 1047

`연월`, `중분류업종명`, `소분류업종명`, `성별`, `이용자수`, `이용건수`, `이용금액`.

- 원본 설명에 제공처가 제주빅데이터센터로 명시되어 있으며 허브에서 유통한다.
- 2023년 9월·11월·12월은 자료가 없다. 결측월을 수요 0으로 바꾸지 않는다.
- `이용자수`에는 `NULL` 58개가 있다. `이용건수`와 `이용금액`에서는 숫자가 아닌 값을 발견하지 못했다.
- 실제 파일에 지역이나 개별 점포 차원이 없다. 지역·개별 음식점 인기도로 해석하지 않고 제주 전체 업종·성별 소비 수요의 입력으로 사용한다.
- 집계마다 동일인이 겹칠 수 있으므로 업종별 이용자수를 합쳐 제주 전체 고유 관광객 수라고 부르지 않는다. 이용자와 관광객의 구분도 이 파일에는 없다.

### 센터 카드 집계 1048

`base_year_month`, `biz_nm`, `user_type`, `sex`, `user_count`, `use_count`, `use_amount`.

- 관측월은 2018년 1월부터 2025년 6월까지 90개월이며 중간 결측월이 없다.
- `user_type` 값은 기타외국, 내국인, 동남아, 법인, 일본, 제주도민, 중국이다. `sex`에는 남성·여성 외에 알수없음이 있다.
- 실제 파일에는 지역·가맹점 식별자가 없다. 제주 전체 업종 소비와 소비주체별 차이를 보여주는 자료다.
- 외식업 1047과 분류체계·표본·기간의 동일성이 검증되지 않았으므로 금액이나 건수를 단순 합산하지 않는다.

### 센터 시간대별 버스 수요 512

`base_date`, `day_of_week`, `base_hour`, `user_type`, `user_count`.

- 실제 파일은 2023년 12월 25일부터 2025년 10월 26일까지다. 공식 상세 메타데이터의 시작 2018년 6월 3일·종료 2025년 10월 19일과 다르므로 분석에는 실제 CSV 범위를 사용한다.
- 시간대는 01시-06시, 07시-09시, 10시-12시, 13시-15시, 16시-18시, 19시-21시, 22시-24시다. 범주별 시간 폭이 같지 않다.
- 정류소·노선·운행시간표·지연·막차·환승 연결 데이터가 아니다. 일자·시간대별 수요 분석에 사용하며 실시간 혼잡이나 실행 가능한 버스 길찾기로 표시하지 않는다.

### 센터 일별 버스 자료 561

`base_date`, `act_type`, `bus_number`, `user_type`, `user_count`.

- `act_type`은 승차·하차·환승이다. 모두 더한 값을 승차 인원이라고 표시하면 중복 집계가 발생하므로 분석 목적에 맞게 구분한다.
- 실제 원자료 행 수는 승차 6,362,795행, 하차 5,794,444행, 환승 1,970,713행이다. 이는 관측 행 수이며 승객 합계가 아니다.
- 좌표·노선별 정차 순서·시간표가 없어 이 자료만으로 길찾기를 만들 수 없다.
- 원본 SHA256은 `7941dce63a51e92313225cf2a5fb517c8b8058e0dda299b36c0b8ae17a7d381d`다.

## 다운로드와 이용조건의 검증 범위

공개 홈페이지 파일 주소에 인증 헤더·사용자 계정·서비스키·쿠키를 제공하지 않은 정상 요청으로 HTTP 200과 실제 CSV를 받았다. 처음 교육부 연계 메타데이터에 남아 있던 구 파일 주소 일부는 HTTP 400을 반환했다. 이를 성공으로 처리하지 않고 공식 홈페이지의 공개 상세 조회 `https://www.jejudatahub.net/api/data/view?id=원본ID`에서 최신 첨부 식별자를 확인해 정상 공개 링크로 다운로드했다. 관련 원문 JSON은 `metadata_*.json`으로 보존했다.

공식 교육부 연계 메타데이터에는 `cc-zero`가 표시되어 있다. 그러나 현재 허브 상세 JSON에는 원문 라이선스와 가공물·모델·원본의 재배포 조건이 명시되지 않았다. 따라서 manifest의 `original_license_verified`와 `redistribution_approved`는 false로 유지했다. 이는 원자료 다운로드 성공 여부와 별개의 항목이다. 원자료 전체의 외부 공개·배포 전에는 제공기관 이용조건을 확인해야 한다. 각 원본의 교육부 연계 메타데이터 URL을 license_evidence_url에 남겼다.

센터 자료를 허브가 유통하는 경우 제공처와 유통 플랫폼을 분리해 기록했다. 같은 원본을 허브와 센터의 독립 데이터 두 종으로 계산하지 않는다.

## API 원자료와 기술문서

597·604·605·607·611·612·613·614의 HWP 기술문서 8개를 다운로드했으며 HWP 복합 바이너리 헤더를 확인했다. 실제 API 원자료는 취득하지 않았다. 일반 API 요청 URL은 `https://open.jejudatahub.net/api/proxy/{dataKey}/{your_projectKey}?{params}` 형태로 사용자 발급 프로젝트키가 필요하다. 로그인·발급된 사용자 키가 없는 상태에서 인증을 대신하거나 우회하지 않았다. 공개 체험키도 사용하거나 별도 보관하지 않았다.

HWP와 JSON 메타데이터를 실제 버스 노선·정류소·카드 관측자료라고 계산하지 않는다. 버스 611·612의 정류소·노선 JSON 데이터가 다운로드되었다고 표시하면 안 된다.

## 주요 산출물

- `manifest.json`: canonical 원본 파일과 기술문서별 다운로드 이력 및 검증 결과.
- `hub_*.csv`: 변형하지 않은 실제 CSV 원본 6개.
- `hub_*.hwp`: API 기술문서 8개.
- `metadata_*.json`: 공식 공개 상세 조회 결과 14개, 관측자료와 별도 분류.
- `food_profile.json`, `csv_profiles.json`: 소규모 파일의 초기 품질 조사. 최종 정확한 수치는 manifest.json을 기준으로 한다.
- `build_download_manifest.py`: 원본 SHA256과 스트리밍 CSV 프로파일을 재계산하는 스크립트.
- `hub_page_780.html`: 공식 웹페이지의 HTML 셸. 데이터나 이용조건 본문으로 계산하지 않는다.

인증값을 포함할 수 있는 프런트엔드 JS는 보존·복사 대상에서 제거했다.
