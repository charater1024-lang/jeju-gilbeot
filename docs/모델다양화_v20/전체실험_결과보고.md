# 제주 길벗 v20 모델 조합 비교

MAE는 관측값과 예측값 사이의 절대 차이를 평균한 값입니다. 구성비가 31%이고 관측값이 30%면 오차는 1퍼센트포인트입니다. 승차 ±20% 기준은 실제 100명이면 80명에서 120명까지의 예측을 허용합니다.

561은 최근 관측에 더 큰 비중을 주는 요일별 중앙값을 적용했습니다. 동일한 28,092건에서 허용오차를 충족한 예측이 335건, 1.19퍼센트포인트 늘었습니다. 평균 절대오차는 0.846% 증가해 사전 허용 범위 2% 안에 들었습니다. 전체 시험 관측 64,315건 중 43.68%에 해당하는 250개 통계 코드가 평가 대상입니다. 서비스에서는 최근 관측이 충분한 202개 코드의 과거 패턴을 제공합니다.

소비·외식은 최근 창과 가중치, Ridge·Elastic Net·커널 회귀, 랜덤 포레스트·부스팅, 소형 신경망, 계층 모형과 고정 앙상블을 비교했습니다. 승차는 요일별 요약, 달력 회귀, 계절 커널, 계층 평활, 트리 계열과 앙상블을 비교했습니다. 기존과 같은 관측값과 허용오차를 쓰고 시험 기간 이전의 3개 소비 검증 구간 또는 2개 승차 검증 구간에서 후보를 골랐습니다. 시험은 선정 후보 하나와 같은 학습 범위의 기존 모델을 비교하는 데 썼습니다. 기존 보고서의 시험 기간을 다시 사용한 후향평가입니다.

1047 후보는 검증 93.50%에서 고정 시험 90.07%로 낮아졌습니다. 소비 초기 참고 Ridge는 가중치 정규화 방식이 운영 Ridge와 달랐습니다. 비교값을 실제 운영 모듈의 동일 범위 재적합 결과로 교정했고, 이미 고정한 후보는 같은 후보로 시험했습니다. 교정 전후 기록을 모두 보존했습니다.

## 검색과 요청 처리

| 평가 대상 | 비교한 조합 | 기존 → 선정 후보 | 적용 결정 |
|---|---:|---|---|
| 관광지 TF-IDF 검색 | 48개 | 59.09% (13/22) → 68.18% (15/22) | 같은 후보 집합에서 첫 결과가 개선됐습니다. |
| 음식점 TF-IDF 검색 | 48개 | 운영 범위와 동일한 시험 필요 | 검증·시험 정답 ID 132개가 겹치고 비교기의 그룹 순서·범위가 운영과 달라 별도 탐색 결과로 기록 |
| 공식 소개 근거를 찾는 도우미 관광 검색 | 48개 | 100.00% (22/22) → 100.00% (22/22) | 같은 후보 집합에서 개선 폭이 0입니다. |
| 걷기·해변·접근성·편의시설 자료 검색 | 48개 | 72.22% (13/18) → 72.22% (13/18) | 같은 후보 집합에서 개선 폭이 0입니다. |
| 여행 도우미 요청 종류 분류 | 36개 | 90.00% (54/60) → 86.67% (52/60) | 같은 문장의 분류기 단독 비교에서 기존 나이브 베이즈의 정답 수가 더 많았습니다. |

검색 수치는 출처 기록에 근거해 작성한 질의 시험입니다. 정답이 첫 결과로 나오거나 지원 범위 밖 질의에 결과가 비어 있으면 성공입니다. BM25, 문자·단어 TF-IDF, 필드 가중치와 순위 결합을 비교했습니다. 관광 전체 색인 실험에서는 100.00% (22/22)가 나왔으나 적용 범위는 검색어가 있고 명시 위치가 없는 첫 페이지에서 5개 이상 결과를 요청할 때의 기존 상위 5개 재정렬입니다. 결과 집합과 출처·지역·신뢰 정책을 보존하며 적합한 첫 결과를 더 자주 보여줍니다.

음식 전체 색인의 탐색 결과는 83.33% (15/18)입니다. 검증·시험 정답 기록 132개가 겹치고, 비교기의 후보 묶음 순서가 화면과 다릅니다. 도우미는 제주데이터허브 780으로 출처를 제한하므로 실제 음식 검색을 평가하려면 그 범위를 따로 재현해야 합니다.

요청 분류의 표는 나이브 베이즈·로지스틱 회귀·선형 SVM의 분류기 단독 비교입니다. 전처리와 해석 규칙을 포함한 기존 전체 파서는 같은 작성 문장에서 81.67% (49/60)입니다. 작성 질의·문장과 실제 이용자의 요청에는 차이가 있어 이 결과로 현장 정확도를 추정할 수 없습니다.
