# 자동 관광 코스 후보의 신뢰성 검사

확인 기준 2026년 11월 1일. 이 검사는 기존 관광 후보의 원자료 연결과 출처 기록을 확인해 자동 코스에 사용할 범위를 보수적으로 좁힙니다. 실제 현장 입구·현재 영업·방문일 운영시간을 전수 확인한 결과는 아닙니다.

## 적용 범위

- 기존 관광 후보 68개와 공식 소개 62개는 그대로 보존합니다.
- 새 자동 추천 조건을 통과한 후보는 40개입니다. 이는 정책을 통과한 후보 수이며 현장 방문 가능성이 확정된 장소 수나 신뢰도 퍼센트가 아닙니다.
- 기존 수동 검색·지도 목록을 삭제하지 않습니다. 자동 관광 코스에는 음식 업소를 관광지로 섞지 않습니다. 음식은 별도 검색과 기존 수동 일정 범위에서 다룹니다.

## 검사 순서

1. 기존 허브·OSM의 정규화 이름 정확 일치와 250m 위치·분류 정책을 확인합니다. v15 정책은 이 선별을 완화하지 않습니다.
2. 68개 원본 후보의 ID·좌표·교차확인 근거·배편/입구 플래그를 고정한 SHA256과 대조합니다. 검색 결과의 점수 같은 부가 필드는 검사를 바꾸지 않습니다.
3. 공식 관광 소개 전체 파일과 개별 소개 레코드의 SHA256을 확인하고 허용된 공식 호스트의 HTTPS 링크인지 검사합니다.
4. 보존한 출처 메타데이터 파일의 실제 SHA256, ID·원문 URL·HTTP 상태와 원본 페이지 해시 필드를 대조합니다.
5. 공식 소개 검토일이 없거나 미래이거나 180일을 넘으면 자동 코스에서 제외합니다. 180일은 소개 근거를 다시 검토하기 위한 관리기한이며 현재 영업을 보장하는 기간이 아닙니다.
6. 배편·별도 실제 탐방 입구가 필요한 장소, 아래의 ID별 검토 대상은 자동 코스에서 제외합니다.

정책 파일이 없거나 손상됐거나 지원하지 않는 정책 ID이면 TrustPolicyError로 자동 추천을 중단합니다. 출처 파일이 달라진 후보를 느슨한 이름 매칭이나 다른 장소의 소개로 대체하지 않습니다.

## 확인한 사실과 확인하지 못한 항목

| 항목 | 반환 상태 | 의미 |
| --- | --- | --- |
| 장소의 명부·지도 연결 | cross_source_verified | 원자료 선별 및 보존된 후보 동일성 확인 |
| 공식 관광 소개 | official_source_record_verified | 보존된 소개·출처 메타데이터의 연결과 무결성 확인 |
| 현재 영업·개방 | not_verified | 실시간 확인 없음 |
| 실제 입구·접근 동선 | not_verified | 대표 좌표를 실제 입구로 승격하지 않음 |
| 운영시간·휴무·요금·예약 | not_verified | 실제 방문일의 이용 가능성을 판단하지 않음 |

메타데이터에 기록된 원본 페이지 해시는 원문을 조사할 때 남긴 값입니다. 전체 원문 HTML을 보관하지 않은 자료이므로, 현재 원문 전체를 다시 내려받아 그 SHA256을 재검증했다는 뜻으로 표시하지 않습니다. 런타임에는 외부 웹 요청이 없고 보존된 로컬 파일만 읽습니다.

넥슨컴퓨터박물관/넥슨뮤지엄은 이미 연결된 공식 장소 문맥을 보존합니다. 이름 변경만을 이유로 자동 제외하지 않고, 명부명과 공식 안내명을 구분하는 알림을 반환합니다.

통제·폐장·공사와 개명 정보는 해당 출처에 담긴 기록입니다. 자동 제외는 현재 해제 또는 운영 상태를 확인하지 못한 경우의 보수적 처리이며, 모든 해당 장소가 현재 폐장됐다는 단정이 아닙니다. 하모는 해수욕장 폐장 기록과 해변 산책 가능 범위를 구분해야 하므로 자동 방문지로 확정하지 않습니다.

## 날짜의 구분

- 공식 소개 편집 근거의 기존 확인일은 2026-10-29입니다. 이를 새 확인일로 덮어쓰지 않았습니다.
- v15 정책 검토일은 2026-11-01입니다.
- 선녀탕·하모·만장굴·이중섭미술관·금능석물원·K아일랜드제주·용머리해안·제주러브랜드의 연결된 공식 공개 페이지는 2026-11-01 다시 열람했습니다. 정책의 public_page_rechecked_at에만 기록합니다.
- 공개 페이지를 읽은 날짜는 현장 상태 검증일이나 해당 원문의 최신 관측일을 뜻하지 않습니다. 현재 영업 확인일은 모두 null입니다.
- 지도 기록의 수정일과 자료를 받은 스냅샷 날짜, 허브 명부의 기준일도 서로 다른 항목으로 표시합니다.

## 구현과 검증

`jeju_agent/place_trust.py`의 `place_trust(root, item, purpose="automatic")`가 적격 여부·항목별 확인 상태·출처 링크와 날짜·제외 이유·미확인 안내를 반환합니다. 임의 신뢰도 퍼센트는 반환하지 않습니다.

신규 테스트 12개가 통과했습니다. 실제 공개 장소 자료와 임시 복사본으로 정책 누락/손상/알 수 없는 버전, 공식 소개 누락·노후·미래 날짜, 원자료 좌표 변조, 출처 파일 변경, 배편·입구 조건, 검토된 개명 알림과 기존 수동 조회 분리를 확인했습니다. 실제 GPS·OS·브라우저 권한을 요청하거나 변경하지 않았습니다.
