## 집단 식음료 구성비 자료

원자료는 제주빅데이터센터 제공 [업종별 성별 카드 이용 정보 허브 1048](https://www.jejudatahub.net/data/view/data/1048)다. 로컬 원본은 `data_raw/hub/hub_1048_5832.csv`이고 SHA256은 다음과 같다.

`518cd18e78141ede90cc5ee7639099282eae4c1557236e4eda6bd295b66e368d`

| 항목 | 실제 사용 내역 |
| --- | --- |
| 원본 행 수 | 28,255 |
| 선택한 원문 행 수 | 3,466 |
| 관측기간 | 2018년 1월부터 2025년 6월까지 연속 90개월 |
| 참고 집단 | resident는 제주도민, tourist는 내국인 |

| 결측값 임의 대체 | 0개 |

8개 업종은 한식·중식·일식·서양식·기타 외국식 음식점업, 비알콜 음료점업, 피자 햄버거 샌드위치 및 유사 음식점업, 빵 및 과자류 소매업이다. 각 월·집단·업종에 남성·여성 행이 모두 있고 일부에는 알수없음 행이 있다. 성별 총계행과 자연키 중복을 허용하지 않는다.

목표 구성비는 해당 월·집단·업종의 성별 분류별 `use_count`를 합하고 같은 월·집단의 8개 업종 건수 합으로 나눈 값이다. `user_count`로 고유 고객 수를 합산하지 않는다. 원거래 수준의 중복 여부까지 독립 검증한 자료도 아니다. 학습은 각 월의 구성비에 같은 가중치를 두므로 전체 기간의 모든 거래를 한 번에 합한 점유율과 다를 수 있다.

### 후보와 기준모형

각 집단에서 월별 구성비 평균과 전체 학습기간 평균을 구한다. 후보는 달력상 같은 월의 과거 평균을 집단 전체 평균 쪽으로 수축한다. 수축 계수 후보는 0, 1, 3, 6, 12이며 검증 구성비 MAE가 가장 작은 값 12가 선택되었다. 수축은 표본이 적은 계절별 분포를 안정화하기 위한 추정 방식이다. 개인 카드 고객을 학습하거나 개인의 음식 선호 확률을 맞춘 결과로 설명하지 않는다.

기준모형 `audience_mean`은 집단별로 전체 학습기간의 월 구성비를 평균한 값이다. 검증에서 후보보다 MAE가 작아 이 기준모형이 운영 선택이 되었다. 월에 따라 출력을 바꾸지 않으므로 현재 UI에서는 월 선택을 숨기고 집단 평균 경향을 사용한다는 안내를 표시한다. 지역 필터는 음식점 명부를 좁히기 위한 조건이며 지역별 소비 모델이 따로 학습되었다는 뜻이 아니다.

후보는 교차 엔트로피에서 아주 작은 차이로 더 낮았지만 선택 기준인 구성비 MAE에서는 기준모형보다 높았다. 다른 지표가 유리하다는 이유로 사전에 정한 선택 기준을 바꾸지 않았다. 구성비 오차가 작다는 사실만으로 모든 업종의 순위가 정확하거나 개별 방문자의 식당 만족도가 높다고 말할 수 없다.

`일반`은 승차권 구분이며 도민·관광객의 거주자 구분이 아니다. 다른 유형의 미관측 셀을 0으로 대체하거나 전체 고유 승객수로 합하지 않는다. 원문 시간구간 라벨은 01시부터 06시, 07시부터 09시, 10시부터 12시, 13시부터 15시, 16시부터 18시, 19시부터 21시, 22시부터 24시다. 비교용 구간 길이는 첫 구간 6시간, 나머지 3시간으로 둔다. 정확한 경계 시각과 실제 차량 출발시각은 원자료에서 독립 검증하지 않았다.

공식 메타데이터의 기간과 다운로드 CSV의 실제 기간은 다르므로 이 평가에는 위 CSV의 실제 기간을 사용했다. 현재일 2026년 10월 27일 기준 마지막 관측 후 366일이 지났다. 현재 실시간 수요를 검증한 점수가 아니다.

### 후보와 기준모형

목표값은 `log1p(user_count / 구간 시간 수)`다. Ridge 후보는 절편, 시간구간 원핫 7개, 요일 원핫 7개, 월 계절 sin·cos를 사용하며 규제 계수 alpha는 1.0으로 고정한다. 장기 시간 추세를 추가하여 현재까지 외삽하지 않는다. 역변환값은 원척도 평균 인원에 대한 불편 추정량이 아니므로 평균과 같은 특성을 보장하지 않는다.

기준모형은 학습 구간에서 요일·시간구간별 시간당 인원의 산술 평균을 구한다. 검증의 시간당 MAE가 후보보다 낮아 `weekday_bucket_mean`이 운영 선택이 되었다. 저장 모델에는 후보 Ridge 가중치와 평균 기준값을 모두 보존한다. API는 선택된 방법과 후보 알고리즘을 구분해 반환한다.

시간당 MAE의 단위는 관측 인원 지표/시간이다. 구간 인원 평가는 시간당 추정에 각 시간구간 길이를 곱해 원래 구간 단위로 복원한다. WAPE는 구간 인원 절대오차 합을 관측 구간 인원 합으로 나눈 비율이며, 예를 들어 기준모형 테스트 WAPE 0.142215는 14.2215%다. 검증과 테스트는 각각 847개 관측이며 관측 구간 인원 합은 각각 1,543,856과 1,581,008이다. 동일인이 다른 시간·날짜에 다시 관측될 수 있으므로 이 합을 서로 다른 사람의 수로 설명하지 않는다.

후보의 오차가 기준보다 크므로 모델 개선으로 표현하지 않는다. 계절 변화와 분포 이동, 특징의 부족, log1p 회귀의 목적과 원척도 오차 차이가 후속 검토 대상이다. 이 결과만으로 어느 원인이 오차 차이를 만들었다고 인과적으로 결론 내리지 않는다.

## 누수와 재현성 관리

검증·테스트의 관측값을 특징이나 평균 기준값 계산에 미리 포함하지 않는다. 원본과 모델의 해시, 실제 관측 범위, 범주·시간구간 정의, 적합 구간과 운영 선택을 산출물에 기록한다. 저장된 모델 구조와 수치·해시를 검사하며 손상된 가중치나 범주 정의를 조용히 받아들이지 않는다. 자료를 갱신하면 이전 점수와 모델 선택을 자동 승계하지 않고 같은 절차를 다시 실행한다.

현재 산출물은 예측구간이나 신뢰구간을 제공하지 않는다. 구간폭·실제 포함률을 평가하지 않았으므로 90% 또는 95% 신뢰도로 맞춘다고 표시하지 않는다. 개별 날짜를 고르는 기능은 학습된 과거 패턴을 조회하는 기능이며 최신 자료로 보정한 실시간 예측이 아니다.

```powershell
python scripts/train_audience.py
python scripts/train_mobility.py
python -m unittest discover -s tests -v
```

음식점·장소 검색 색인의 프로파일은 `data_reference/catalog_profile.json`에 별도로 있다. 현재 검색 색인 5,381행의 정리가 모델 평가용 정답을 만들었다는 뜻은 아니다. 상세 도민·관광객 소비 모형과 일반 승차 모형은 장소 순서를 학습하지 않는다. 실제 일정 생성은 규칙 기반 제약 탐색이고, 이름이 붙은 Agent들은 로컬 분석 도구의 실행 흐름이다.

## 결과를 설명할 때의 한계

집단 구성비는 선택된 8개 업종 안의 과거 카드 이용건수 분포다. 제주 전체 소비·모든 관광객·모든 결제수단의 대표성을 검증하지 않았다. 명부의 식당 예시는 업종 경향을 참고한 이름순 후보이며 개별 점포 인기 순위가 아니다. 일반 승차 패턴은 제주 전체 집계이고 특정 노선·정류소·좌석·운행시간을 알려주지 않는다.

버전 2의 `models_real_context`와 내국인·여성 구간 720행 Ridge 실험은 별도 역사적 산출물이다. 이번 성별 합산 2집단 구성비 모델과 자료 선택·목표·분할·지표가 다르므로 원건수 MAE를 구성비 MAE와 섞어 비교하지 않는다. 합성 장소와 합성 방문량을 사용한 개발 체험의 점수도 이 실자료 검증의 성과에 포함하지 않는다.

서비스의 다음 검증은 최신 자료 재확보 후의 시간 분할 재평가, 방문자 과제 수행과 이해도, 실사용 조건의 유효 일정 비율, 센터 기준 PC에서의 설치·응답·메모리 확인이다. 현재 문서에는 아직 확정되지 않은 센터 현장 성능이나 포터블 런타임 측정치를 성과로 제시하지 않았다.
