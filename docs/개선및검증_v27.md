# 제주 길벗 v27 개선 범위와 확인 기준

공식 소개에서 찾은 장소의 근거를 확인하고 일정에 담은 뒤, 도착 조건에 맞춰 남은 여행을 조정하는 흐름을 개선했다. 확인된 이름이 있으면 해당 장소를 먼저 연결하고, 일반 주제는 공식 소개와 명부의 단어·문자 TF-IDF로 검색한다. 소개를 조회할 수 있어도 입구, 배편 또는 현장 통제가 따로 확인되어야 하는 경우에는 사유를 보여주고 자동 코스 편입과 구분한다. 지역을 직접 지정한 상담에는 위치가 필요할 때만 동의 화면을 열고, 검색 조건이 바뀌면 이전 페이지의 결과가 섞이지 않게 했다.

자동차 일정은 선택한 방문 순서의 로컬 OSM 도로 거리로 시간과 이동비를 재검사한다. 도로 연결을 확인할 수 없으면 보정한 좌표 거리로 계산하고 화면에 근거를 표시한다. 도로 재검사는 먼저 고른 순서에 적용하므로 모든 조합을 도로 거리로 다시 탐색하는 데까지 이르지는 않는다. 실제 교통과 현장 통제는 방문 전에 확인해야 한다. 구간 거리·시간과 이전 코스로 되돌리기는 Wanderlog 공식 안내에 있는 기능을 참고했다. 비짓제주도 관광지·테마 안내와 AI 여행 플래너를 제공한다. 길벗의 기능은 운영 중인 공개 자료와 센터의 로컬 실행 조건에 맞춰 구현했다. [Wanderlog 경로 최적화](https://help.wanderlog.com/hc/en-us/articles/13545624787867-Optimize-route) · [Wanderlog 여행 지도](https://wanderlog.com/travel-maps) · [비짓제주](https://www.visitjeju.net/kr)

여행 중에는 현재 공개 관광지를 확인하고 기존 도착지와 마감을 유지하면서 제주 전체에서 대체 장소를 찾거나 도착지만 계산한다. 도착지만 계산한 결과는 현재 일정 아래에 별도로 표시한다. 일정 변경 후 이전 코스로 한 번 돌아갈 수 있다. 재계산한 HTML 일정에는 공개 기준점 이름과 출발 시각, 기존 마감을 넣으며 개인의 정밀 좌표는 제외한다.

센터 체험은 공개 1048 CSV의 같은 집단에서 두 관측 월을 골라 이용건수와 비중 변화를 비교한다. 이용자가 원할 때 이미 검증된 1048 월별 회귀 모델의 참고값을 함께 읽는다. 관측값과 학습 모델의 참고값은 표에서 구분한다. 파일 내용과 관측 집계는 브라우저에서 처리하고, 참고값을 읽을 때에는 월과 집단만 로컬 서버로 요청한다. 센터 방문 승인 자료는 데이터별 명세와 반출 기준을 적용한다. [공개 1048](https://www.jejudatahub.net/data/view/data/1048) · [센터 반출 기준](https://jejudatahub.net/community/notice/view/48)

공식 소개의 기존 작성 질의 시험은 변경 전후 모두 **22/22**였다. 이번에 발견한 장소명 혼동, 띄어쓰기, 별칭 및 미지원 요청을 재현한 별도 **작성 회귀 질문 10건**은 **3/10에서 10/10**으로 개선됐다. 이 결과는 실제 이용자 전체의 적합률과 구분한다. 소비·외식 구성비의 기존 모델과 평가 원본은 그대로 사용한다. 93%는 프로젝트에서 검토하는 내부 목표이며 대회의 공통 요건으로 사용하지 않는다. [운영 모델과 기존 평가](운영모델_v23.md) · [대회 공식 안내](https://daker.ai/public/hackathons/jeju-ai-bigdata-agent-challenge)

기존 감사의 공항–천지연폭포 사례에서 **138분은 체류를 뺀 이동 시간**이었다. 기존 09:00 출발의 체류 포함 도착 추정은 12:48이었다. 같은 방문 순서에 로컬 도로 86.014km를 적용하면 체류 포함 239분으로 12:59 도착, 추정 이동비 21,504원이 되어 12:48·20,000원 조건에서 각각 11분·1,504원 초과로 처리한다. 이 수치는 개발 PC의 동일 원본과 가정 속도로 계산한 재현 사례다. [기존 점검 보고서](서비스_사용자및대회점검_v26_20261106.md)

로컬 브라우저에서 성산일출봉의 소개와 자동 코스 제한, 용두암 소개에서 일정 담기, 위치 안내를 건너뛴 북부 해변 상담, 검색어 변경 뒤 페이지 초기화를 확인했다. 용두암에서 12:00에 공항으로 바로 출발하는 대안은 12:06 도착과 추정 이동비 768원을 보여줬다. 기존 일정은 남았고, 재계산 뒤 되돌리기로 기존 방문 순서를 복원했다.

공개 1048 원본을 선택하니 2025년 6월 제주도민의 8업종 이용건수는 785,479건, 2024년 6월은 780,014건으로 집계됐다. 비중 변화가 가장 큰 항목은 비알콜 음료점업의 +1.39%p였다. 모델 참고값을 별도 열로 불러오는 것과 파일 초기화로 집계와 비교 상태가 사라지는 것을 확인했다. 센터 운영 상태 확인에서 자동 코스 후보 40곳, 재검토 기한 안의 소개 62곳과 도로 파일을 확인했다.
