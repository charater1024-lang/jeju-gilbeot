# 제주 길벗 v26 사용자 경험·AI·센터 제출 점검

2026년 11월 6일 KST · 로컬 v26 실행본 기준

우선순위는 **장소를 정확히 찾고, 찾은 장소를 바로 일정에 담고, 마감에 맞춰 돌아갈 수 있도록 돕는 것**이다. 브라우저에서 공항 출발 자동 코스와 여행 중 재계획은 끝까지 동작했다. 그보다 앞선 공식 소개 검색에서 정확한 장소명을 입력해도 다른 장소가 나오는 문제가 있고, 일정의 시간 판정과 지도에 그려지는 도로 거리에는 차이가 있었다. 센터 이용자에게는 별도로 **공개 데이터를 비교하고 차이를 설명받는 한 가지 완결된 체험**이 필요하다.

개발 노트북의 로컬 브라우저에서 홈, 상담, 지도·먹거리, 공식 소개, 일정·재계획, 데이터 안내와 공개 1048 CSV를 확인했다. 재계획은 390px 뷰포트에서도 실행했다. 코드와 공개 데이터로 재현한 항목은 해당 행에 구분했다. 센터 실장비, 센터 승인 자료, 최종 제출 ZIP의 실행은 확인 범위 밖이다. 대회 공식 안내와 공개 게시판 19건의 목록, 운영진 답변 기록, 센터 반출 공지를 대조했다. | 허브 1047 외식 비중 | 과거 평가에서 ±0.25%p 이내 1,790/1,974건, 평균 오차 0.097%p. 이용 비중 상위 10업종의 평균 오차는 0.490%p다. | 전체 오차와 상위 업종 오차를 함께 표시한다. 소규모 업종이 많은 자료에서는 전체 적중률만으로 많이 이용하는 업종의 오차를 설명할 수 없다. |

## 기능을 추가한다면

1. **여행자용 ‘장소 찾기 → 담기 → 복귀 가능 확인’**을 첫 개선으로 권한다. 정확한 이름 검색을 복구하고, 공식 소개에 ‘지도에서 보기’와 ‘일정에 담기’를 연결한다. 이어서 남은 시간이 부족하면 원래 도착지로 이동하는 선택과, 동의를 받아 찾는 대체 장소를 제공한다. 이 흐름에서 모델은 표현이 다른 요청과 관련 자료를 연결하고, 규칙은 확인된 출처와 일정 제약을 검사한다.
2. **센터용 ‘자료에서 답 찾기’**는 공개 1048 한 가지로 끝까지 완성한다. 예를 들어 도민 집단의 두 관측 월을 선택하면 실제 이용건수와 8개 업종 구성비의 변화, 분모와 기간을 표시한다. 모델의 월별 참고값을 비교할 경우 같은 집단·분모를 쓰고 관측값과 구분한다. 이후 현장 승인과 표본을 확보하면 센터의 `카드 이용 현황(읍면동)_v02`를 후보로 삼을 수 있다. 원본의 집계 단위와 결측값 처리, 출력 반출 절차는 센터 명세를 먼저 확인한다. [센터 자료 명세](https://jejudatahub.net/center/data) · [공개 게시판](https://daker.ai/public/hackathons/jeju-ai-bigdata-agent-challenge?section=board)
3. **실제 과제로 평가한다.** 제출 자료의 대표 장면은 정확한 이름으로 찾기, 공항 복귀 조건으로 코스 만들기, 시간 부족 시 재계획, CSV에서 변화 읽기 네 가지로 잡는다. 검색에는 첫 결과 적합률과 오답률을, 일정에는 완료율과 조건 위반을, CSV에는 원본 집계와 일치하는지를 사용한다. 현재의 고정 시험 점수와 새 사용자 시험 결과를 구분해 제시한다.
