# v15 제안서 개정 내용

기존 v14 문서와 builder를 보존하고, 새 폴더에서 개인 개발자 제안서의 구현 상태를 v15에 맞췄습니다. 최종 문서는 10쪽이며 표 11개와 그림 4개를 유지했습니다.

- 1~3쪽: 출발지 명시적 확인과 복귀지 연결, 자동 코스, 장소 제외 후 재추천을 구현 완료 항목으로 반영했습니다.
- 4쪽: 교차확인 관광 후보 68개와 자동 정책 충족 후보 40개를 구분하고, 출처 무결성·공식 소개·접근 제외·장소별 예외와 현재 운영 미확인을 명시했습니다.
- 5~6쪽: 기존 소비·승차 모델의 쉬운 허용오차 지표와 MAE를 유지했습니다. 분류 Accuracy, 개인별 추천 정확도와 현장 성능으로 해석하지 않도록 설명했습니다.
- 7쪽: 중앙 run_agent의 요청 확인부터 검색·출처 검사·제한된 후보 탐색·시간과 복귀 재검사·OSM 참고 경로·근거 표시까지 연결했습니다. 추정 이동비 조건을 전체 여행 예산과 구분했습니다.
- 8~10쪽: 실제 입구·운영 정보, 신규 자료 재평가, 검색·코스 품질, 실제 브라우저와 센터 PC 검수를 남은 과제로 정리했습니다. 확정된 203 Python 검사·15 UI 파일·8 JS 문법 검사·57 API 요청·4페이지·신규 Agent 13조건 결과를 반영했습니다.

실시간 교통·인기 경로 학습·음식점 자동 편입은 구현된 기능으로 표시하지 않았습니다. 가상 컨소시엄·협약·실적을 추가하지 않았습니다.

문서 생성에는 번들 Python을 사용했습니다. 새 DOCX에 canonical render_docx.py를 1회 실행했으나 Windows 번들 soffice.exe 부재로 실패했고, 보이지 않는 Microsoft Word COM 인스턴스로 DOCX에서 PDF를 내보냈습니다. 번들 Poppler 144dpi의 최종 10쪽 PNG를 전부 원해상도로 열어 글자·표·그림·여백을 검토했습니다. 문서검수_v15.json에 결과와 SHA-256을 보존했습니다.
