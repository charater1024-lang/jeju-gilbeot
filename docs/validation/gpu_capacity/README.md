# GPU 상주 동시 입력 실측과 센터 사양 설계

2026-11-08. 현재 개발 PC에서 **33개 유효 구간·4,560요청·HTTP/응답형식 오류0건**을 확인했다. E5 의미 검색 모델1개를 DirectML GPU에 상주시킨 상태다. 동시에 들어온 입력을 순서대로 처리하는 구조이며, 동시 요청 수는 동시 사용자 수나 GPU 배치 크기를 뜻하지 않는다.

## 실측 장비와 실행 조건

- CPU 13th Gen Intel(R) Core(TM) i9-13980HX, 물리24코어·논리32개, RAM64GB(가용 물리 총량 63.63GiB).
- NVIDIA RTX4090 Laptop GPU, 전용 메모리16GB, 드라이버621.14, Windows11.
- 격리된 loopback8791 시험 서버 PID48008; 기존8765서비스와 사용자 위치·브라우저 설정은 건드리지 않았다. 시험 서버는 완료 후 종료했다.
- E5-small FP32 ONNX, 모델 SHA256 cf3f713592d6a68b340057834342b44812495437749855e43c9af914e739fe54, 입력64토큰·batch1·동일세션1개 상주. 실제 DirectML 커널 실행과 요청별 GPU성공 카운터 증분을 확인했다.
- 회귀·HGB·규칙·일정 탐색은CPU다. 도로 최근접노드의 선택형 GPU도 준비됐으며 이 메모리를 포함한다. A*와 일정순서 탐색은CPU다.
- 87토큰 긴 질문은 자르지 않고 CPU INT8로 전환했다. 기존 GPU 모델은 유지됐고 이후 짧은 질문의 GPU 복귀도 확인했다.

## 센터 사양에 적용할 설계 판단

센터 기준은 i7-8700 / GTX1060 / RAM32GB다. 현재 개발 PC의 응답시간을 이 장비의 실측으로 환산하지 않는다. GTX1060은3GB/6GB형이 있어 둘을 나누어 본다.

- 서비스 메모리 여유 예산 제안: **RAM6GiB·전용VRAM2GiB**. 관측 생애RAM최고 대비약1.65배, 전용VRAM표본최고 대비약2.66배다. 실제예약·최소사양·센터보장값은 아니다.
- RAM32GB 중 서비스예산6GiB를 두고 OS·브라우저·다른 프로그램 공간을 별도로 남긴다. 3GB/6GBGPU도 화면·다른앱의VRAM을 별도로 남겨야 하며 DML드라이버·하드웨어별 중간버퍼 크기는 달라질 수 있다.
- 보수적인 초기 운영 설계안은 일반 입력4개, 무거운8곳코스 입력2개를 기준으로 별도 대기열을 관리하는 것이다. 이 수치는 센터실측이나 현재 적용한 제한이 아니다. 무거운코스2개 조합 자체는 본표에서 측정하지 않았고 1/4/8/16개 관측보다 낮춘 여유 설계안이다.
- 현재서버의 계산슬롯8·연결48 설정은 변경하지 않았다. 단순한 접속자 수와 입력 수를 혼동하지 않는다.
- 현재PC의 시험프로세스만12개 논리CPU로 제한한 민감도 시험도 했다. 의미검색16개 P95 0.80초, 혼합16개 0.57초였다. 설정은 복원했으며 i7-8700 또는 GTX1060을 재현한 시험은 아니다.

센터 현장에서 추후 성능을 확인하겠다는 계획은 기획서에서 삭제했다. 대신 위의 개발PC관측·메모리설계안·적용범위만 구분해 기록한다.

## 성공과 실패를 구분하는 기준

성공은 HTTP200과 정상 JSON형식이다. 의미검색 빈 결과 428건도 포함된다. 이 빈 결과는 개발용6질문 중 테디베어 관련 지원질문의 반복에서 나왔으며 ‘미지원 질문’으로 단정하지 않는다. 검색 점수의 거절 결과와 HTTP오류를 구분하고, 이 시험에서 검색 품질·식당 만족도·추천 정확도를 측정하지 않았다. GPU 전용872건과 혼합 중842건, 합계1,714건의 GPU실행 카운터 증가를 확인해 빈 결과여도 모델 실행은 검증했다.

최대8곳코스의 초기 시험기에서 잘못된3곳 검증범위를 적용한 시행1건은 setup_trials에 원본·SHA와 함께 보존하고 최종33구간에서 제외했다. 서비스는HTTP200으로8곳을 반환했다. 검증범위만 바로잡았으며 원자료·모델·임계값·서비스 코드는 수정하지 않았다.

## 재현 자료

results/에는 프로토콜·PID·기기·각 요청·메모리표본·시작·유휴·종료 기록이 있다. summary.json과 각stage SHA256으로 대조한다. scripts/의 실행도구는Windows64용이며 로컬 runtime/python.exe와 기존 모델·패키지가 필요하다. 모델과vendor폴더는 프로젝트의 기존 자산을 사용한다. launcher가 만든 PID/포트만 중단하며 GPU가동중인 프로세스를 임의로 종료하지 않는다.
