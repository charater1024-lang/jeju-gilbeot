# 외식 세부업종 구성비 모델 결과

2026년 11월 4일. 제주데이터허브 1047의 실제 카드 집계로 학습한 CPU 모델이다. 현재 1048 소비 모델은 보존하고, 세부 외식업종을 비교하는 분석을 추가한다.

## 사용 범위

사용자가 월과 업종을 선택하면 해당 월의 외식·간식 세부업종별 이용건수 구성비를 계산한다. 예를 들어 한식으로 좁히면 일반한식/백반·해장국/감자탕·순두부전문 등 실제 원자료의 업종명을 반환한다. 필터를 적용해도 구성비의 분모는 전체 학습 대상 94개 업종으로 유지한다. 상위 12개만 표시하면 그 합계는 100%보다 작다.

이 결과는 카드 집계의 계절별 통계 패턴이다. 개인 취향, 개별 식당의 인기, 관광객 집단 선호를 나타내지 않는다. 1047에는 지역과 도민·관광객 구분 필드가 없다. 기존 1048 자료와 건수를 합산하지 않는다.

## 모델 선택

직접 다중출력 계절 Ridge와 중분류·소분류를 나눠 학습하는 계층형 계절 Ridge를 비교했다. 두 방식 모두 최근 관측 가중, 기간창, 월의 사인·코사인 특성, L2 정규화를 사용한다. 기간창 4종, 최근 가중 반감기 4종, 계절 차수 3종, 정규화 3종을 조합해 총 288개를 검증했다.

선택된 운영 모델은 **직접 다중출력 계절 Ridge**다. 최근 12개월, 반감기 6개월, 계절 차수 2, 정규화 계수 10을 사용한다. 계층형 모델은 후보로 평가했지만 검증 평균절대오차가 더 작은 직접 모델을 채택했다. 운영 시에는 전체 69개월의 자료에서 동일한 학습 설정을 다시 적용했으므로 최근 12개월인 2024년 자료가 계수 적합에 사용된다. 런타임 LLM·외부 모델 API·GPU·추가 pip 패키지는 필요 없다.

선택 영수증 해시는 `f7c7d887484c683bbf5f0606c57cf147de635d70f447126e53c0de5276abec9b`다. 시험 자료를 설정 선택에 사용하지 않았다. 한 번 계산한 시험 결과를 보고 재튜닝하지 않았다. 향후 새로운 관측이 들어오면 별도 미래 기간 검증이 필요하다.

## 오차와 비교 결과

퍼센트포인트는 구성비의 차이다. 실제 구성비 10%에 예측 11%라면 오차는 1퍼센트포인트다.

| 시험 지표 | 선택 모델 | 동일 적합 범위 전체 평균 | 선택 설정의 최근 가중 평균 |
|---|---:|---:|---:|
| 평균절대오차 MAE, 퍼센트포인트 | 0.097197 | 0.162927 | 0.099718 |
| RMSE, 퍼센트포인트 | 0.251761 | 0.465235 | 0.260332 |
| 구성비 WAPE | 9.1365% | 15.3151% | 9.3735% |
| 실제 이용비중 상위 10개 업종 MAE, 퍼센트포인트 | 0.490223 | 0.884459 | 0.508548 |

평균절대오차는 전체 평균 대비 **40.34%** 작았다. 같은 최근 가중 평균 대비 추가 개선은 **2.53%**다. 큰 개선의 상당 부분은 최근 관측을 반영한 효과이며 복잡한 계절 특성이 만든 추가 개선은 제한적이다. WAPE의 분모는 시험의 실제 구성비 합계이며 월마다 그 합은 1이다.

| 설명용 허용오차 | 시험에서 해당 범위에 든 수 | 비율 |
|---|---:|---:|
| ±0.25퍼센트포인트 | 1,790/1,974 | 90.68% |
| ±0.5퍼센트포인트 | 1,892/1,974 | 95.85% |
| ±1퍼센트포인트 | 1,944/1,974 | 98.48% |

분모는 21개월×94업종인 **1,974개 월·업종 셀**이다. 구성비가 작은 업종이 많아 허용오차 내 비율이 높게 나온다. 이 값을 분류 accuracy, 추천 성공률 또는 사용자 만족도로 제시하지 않는다. 상위 10개 업종의 MAE는 0.490223퍼센트포인트이며 한 셀의 최대 오차는 2.327650퍼센트포인트다.

## 관측 금액과 화면 해석

각 업종에 2024-01~2024-12의 실제 이용금액 합계÷이용건수 합계를 함께 제공한다. 이는 **관측 결제 건당 금액**이고 ML 예측값이 아니다. 한 건의 결제에 여러 명의 식사와 여러 품목이 포함될 수 있어 1인 식사 가격·현재 메뉴 가격·여행 예산 제약으로 사용하지 않는다.

각 결과에는 업종별 시험 MAE, 원출처 링크, 실제 관측 기간, 모델 평가 지표와 설명을 포함한다. 예측 구성비 합계는 100%로 유지하되 업종 검색 시 재정규화하지 않는다.

## 재현과 검증

학습은 프로젝트 루트의 `runtime/python.exe scripts/train_dining.py`로 재현한다. 성능 전체 내역은 `models_dining/dining_metrics.json`, 서비스 모델은 `models_dining/dining_model.json`이다. 모델과 원자료 해시 불일치, 손상된 계수, 잘못된 입력은 오류로 중단한다.

`tests/test_dining_model.py`는 실제 원본의 누락 월·완전 관측 범위, 날짜 분리, 허용오차 분모, 12개월 구성비, 검색 시 분모 유지, 실제 결제 금액 일치, 손상 모델 차단, 재학습 바이트 재현을 확인한다. 기능 테스트 수는 모델 정확도로 표시하지 않는다. 전체 서비스 연결과 화면 검증은 통합 검증 결과에서 별도 확인한다.
