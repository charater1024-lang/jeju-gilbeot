# 제주길벗 기획서 레퍼런스 검토와 개정 방향

검토일 2026년 11월 3일

이번 개정은 공개 수상작 제안서에서 설명 순서와 근거 제시 방식을 참고하고, 제주길벗의 현재 구현을 심사자가 이해하기 쉽게 다시 정리하는 작업이다. 문장을 격식 있게 바꾸는 데 그치지 않고, 이용자가 겪는 문제와 실제 결과를 앞에 배치한다. 제안 주체는 개인 개발자이며 구현 내용은 v16을 기준으로 한다.

## 검토한 공개 제안서

아래 세 자료는 경상남도 빅데이터센터가 실제 수상작 결과물로 공개한 아이디어 제안서다. 모집 공고나 빈 서식과 구분했으며, PDF의 전체 텍스트를 읽고 관련 페이지를 확인했다. 게시일은 기관 게시물에 적힌 날짜로, PDF 자체의 작성일을 별도로 추정하지 않았다.

이 자료에 적힌 자체 설문, 이용자 평가, AI 정확도, 매출 목표와 협력관계는 작성자의 주장이다. 제주길벗의 조사 결과나 실적으로 옮기지 않으며, 다른 서비스에 대한 단정적인 평가도 차용하지 않는다.

## 기존 기획서에서 바꿀 부분

기존 기획서는 실제 구현과 평가 결과를 충실히 담았지만, 개발 내역을 설명하는 부분이 여러 장에 걸쳐 반복된다. 검색, 출발지 확인, 자동 코스, 저장 기능을 장마다 다시 나열하면서 제안의 목적과 개발 인계 문서의 성격이 섞여 있다. 개정본에서는 이용 흐름을 한 번 설명하고, 뒤의 장에서는 데이터·검증·운영에 필요한 내용만 이어간다.

여러 장이 요약 문단, 표, 소제목, 제한사항이라는 비슷한 순서를 반복한다. 표의 수가 많다는 사실보다 서로 다른 내용을 같은 리듬으로 배치한 점이 읽는 흐름을 단조롭게 만든다. 비교할 값은 표로 정리하되, 제안 배경과 판단 이유는 짧은 문단으로 연결하고 실제 코스 사례와 간단한 도식을 필요한 위치에 배치한다.

첫 장에 소비·승차 모델의 허용오차 내 비율을 함께 놓으면, 관광 코스 자체의 추천 정확도처럼 받아들일 가능성이 있다. 개정본은 모델 평가를 한 쪽에 모아 예측 대상과 오차를 설명하고, 코스 추천의 이용자 만족도나 현장 정확도를 평가한 수치와 구분한다. 기능 테스트의 통과 건수도 여행 품질의 수치로 제시하지 않는다.

## 개정본 구성 방향

개정본은 8쪽을 기준으로 구성한다. 먼저 실제 이용 장면과 코스 결과를 보여주고, 자료의 신뢰성, AI의 역할, 평가 결과, 실행 계획 순으로 읽히도록 정리한다. 기존 v15 정식 기획서는 보존하고, 새 문서는 v16의 구현과 검증 결과를 반영한다.

| 구성 | 독자가 확인할 내용 | 표현 방식 |
|---|---|---|
| 제안 개요 | 누구의 어떤 문제를 해결하며 현재 무엇을 제공하는가 | 짧은 설명과 제안 범위 |
| 실제 이용 사례 | 조건을 넣으면 어떤 코스와 안내를 받는가 | 공개 장소를 사용한 실제 실행 사례 |
| 장소와 정보 확인 | 어떤 관광지는 코스를 만들고 어떤 경우는 중단하는가 | 출처, 확인일과 확인 필요 사유 |
| 데이터와 AI의 역할 | 각 자료와 모델이 어디에 사용되는가 | 기능과 자료를 연결한 간결한 표 |
| 모델 평가 | 무엇을 예측하며 오차가 어느 정도인가 | 소비·승차 평가를 한 쪽에 정리 |
| 실행과 개인정보 | 센터 PC에서 어떻게 실행하고 위치를 어떻게 다루는가 | 실제 실행 방식과 간단한 흐름도 |
| 개발 및 확인 계획 | 다음 작업에서 무엇을 만들고 어떻게 확인할 것인가 | 일정, 산출물과 확인 기준 연결 |
| 활용 범위와 근거 | 어떤 기대를 검증해야 하며 참고한 자료는 무엇인가 | 현재 결과와 앞으로 측정할 효과 구분 |

일정은 막연한 고도화 계획 대신 입구·운영정보 검수 기록, 검색·코스 평가표, 센터 PC 시연 기록처럼 확인 가능한 산출물에 연결한다. 앞으로 수행할 검증은 계획으로 표시하고 이미 완료한 조사나 현장 실적으로 쓰지 않는다. 기간과 수치는 제안용 계획과 실제 측정 결과를 구분한다.

## 문장과 근거를 다루는 원칙

설명에는 제주길벗이 실제로 하는 행동을 쓴다. 예를 들어 신뢰를 높인다는 요약어만 두지 않고, 공식 소개와 위치 근거를 함께 보여주며 확인이 필요한 관광지가 있으면 사유를 알리고 일정을 중단한다고 설명한다. 개인 개발자가 맡는 범위와 다음에 확인할 일을 분명히 하되, 존재하지 않는 컨소시엄·기관 협약·인원·실적·이용자 조사·매출을 만들지 않는다.

공개 제안서에서는 설명 순서와 근거를 배열하는 방법만 참고한다. 원문의 문구와 이미지를 모방하거나 전문을 수록하지 않으며, 참고 자료의 사업 성과를 제주길벗의 실적으로 사용하지 않는다. 이번 개정의 판단 기준은 심사자가 대상·문제·서비스·근거·실행 계획을 이해하기 쉬운지에 두며, 작성 주체를 판별하거나 특정 탐지 결과를 보장하는 작업으로 제시하지 않는다.
