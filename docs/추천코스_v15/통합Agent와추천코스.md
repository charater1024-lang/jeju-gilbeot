# 제주 길벗 v15 통합 Agent와 추천 코스

2026-11-01 기준. 서비스는 실제 관광 후보만 사용하며 자동 추천 요청을 중앙 조정기에서 처리합니다. 이전 v14는 기능별 도구 연결이 중심이었고 v15는 후보 검색부터 신뢰성 검사·장소 선택·일정 재검사·경로 참고와 설명까지 한 요청 안에서 수행합니다.

## 통합 Agent가 하는 일

사용자가 확인한 출발지와 복귀지 → 지역·테마 검색 → 신뢰성 검사 → 실제 장소 자동 선택 → 시간·이동비·복귀 조건 재검사 → 로컬 지도 참고 경로 → 선택·제외 근거와 확인사항 제공

- 중앙 진입점은 POST /api/agent/plan이며 jeju_agent/orchestrator.py의 run_agent()가 조정합니다.
- 학습된 관광 TF-IDF, 출처 정책, 장소 선택·제약 탐색과 로컬 도로 도구를 호출합니다. 실행 흔적은 결과의 trace에 나타납니다.
- 실행 중 LLM을 호출하거나 원본 수정·재학습·예약·결제를 자율 실행하지 않습니다.
- 소비·승차 모델은 각각 과거 소비 경향과 이동 시간대의 별도 참고 분석입니다. 전체 집계를 개별 관광지 인기도나 방문순서 정답으로 사용하지 않습니다.
- 기존 담은 장소의 순서 계산과 검색·상담도 유지합니다. 모든 개별 기능이 생성형 다중 Agent로 바뀌었다는 의미는 아닙니다.

## 신뢰성을 확인하는 범위

기존 관광 후보68개는 유지하고 자동 코스용으로는 현재 정책을 통과한40개를 사용합니다. 이 수는 현장 인증이나 현재 영업 확인 수가 아닙니다.

| 항목 | 검사와 표시 | 남는 한계 |
| --- | --- | --- |
| 장소 정체성 | 허브·지도 이름·250m 위치·분류 교차확인과 원본 후보 fingerprint | 주소·실제 입구 전수 검증 아님 |
| 공식 소개 | 허용된 공식 출처, 소개 record·메타데이터 receipt의 SHA256과 기록된 원문 hash 일치 | 원문 HTML 전체를 보존·재해시한 것으로 과장하지 않음 |
| 정보 기준일 | 명부 기준일·지도 수정일·소개 확인일을 구분 | 현재 운영 확인일로 바꾸지 않음 |
| 접근 제한 | 배편·탐방 입구 필요 장소와10개 ID별 예외를 자동 후보에서 제외 | 알려진 기록의 보수적 처리이며 현재 통제 해제 전수 확인은 아님 |
| 영업·요금·예약 | 미확인 상태와 방문 전 원문 확인을 명시 | 현재 방문 가능 또는 총예산 충족을 보장하지 않음 |
| 신뢰성 정책 | 누락·손상·미지원 버전이면503과 재검토 안내 | 임의의 신뢰도 퍼센트를 만들지 않음 |

공식 소개180일은 내부 재검토 관리기한입니다. 그 기간 동안 영업을 보증한다는 뜻이 아닙니다. 기한이 지나면 자동 코스에서 제외합니다. 넥슨 명칭 변경과 해변의 산책·경관 목적 및 수영 가능 미확인 같은 장소별 주의사항도 화면과 HTML 일정에 보존합니다.

## 화면에서 사용하는 방법

1. run_center.cmd로 실행하고 내 여행 화면을 엽니다.
2. 담은 장소 순서 만들기 또는 조건에 맞는 코스 추천을 선택합니다.
3. 탐색 기준 위치 적용, 제주공항 출발 확인, 직접 입력 좌표 확인 중 하나로 실제 출발지를 확인합니다. 공항 기본값은 자동 확정되지 않습니다.
4. 출발지 복귀 여부, 날짜·시간, 수단, 추정 이동비 한도와 최대 방문 수를 지정합니다. 자동 모드에서는 지역과 관광 테마를 고를 수 있습니다.
5. 생성한 코스의 출처·확인일·선택 이유·제외 이유를 확인합니다. 이 장소 빼고 다시 추천으로 제외 후 재계산할 수 있습니다.
6. 지도 참고 경로를 보고 HTML 일정을 저장합니다. 저장 파일에는 공식 소개 출처·기준일·주의사항이 남고 개인 출발지 좌표·라벨은 포함되지 않습니다.

기기 위치는 명시적으로 적용한 경우에만 사용합니다. 정밀 좌표는 입력란과 저장 파일에 노출하지 않으며 알려진 추정 오차를 표시합니다. 수신 시각은 현재 위치 API 연결에서 제공되지 않아 미제공으로 안내합니다. 권한 취소·위치나 조건 변경·새 여행·페이지 종료 시 이전 일정과 늦게 도착한 응답을 무효화합니다. 실제 사용자 GPS 권한은 자동으로 허용하지 않습니다.

## 코스 선택과 시간 계산의 의미

자동 선택은 검색 조건을 통과한 실제 후보 중 상위24개와 beam64의 제한된 탐색을 사용합니다. 방문 가능한 장소 수를 먼저 고려하고 같은 수에서는 복귀를 포함한 추정 이동시간·이동비를 비교합니다. 전역 최적, 개인 취향 학습, 인기 순위를 주장하지 않습니다.
최종 선택된 최대8개 장소는 기존 순열 검사로 시간과 복귀를 다시 확인합니다. 장소 체류는 계획용 값 또는 기본90분이고, 자동차 이동은 직선거리 보정1.35·가정속도35km/h·보정거리1km당250원의 이동비를 사용합니다. 도보는 보정1.2·4km/h입니다. 입장·식사·주차·대여료는 별도이며 전체 예산 충족 여부는 미검증입니다.
OSM 자동차 도로 연결은 참고 경로입니다. 회전 제한·현재 통제·실시간 교통·실제 입구를 검증한 내비게이션이 아니며 도로 연결 실패 시 방문 순서 직선을 명시해 표시합니다. 버스 운행 시간표가 없으므로 버스 자동 코스는 지원하지 않습니다.
