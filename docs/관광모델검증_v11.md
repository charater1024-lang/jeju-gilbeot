# 관광 검색 모델 검증 v11

관광 검색은 실제 명칭과 관측 분류의 TF-IDF 표현을 학습한 비지도 검색입니다. 점포나 관광지의 인기, 만족도, 방문량을 예측하지 않습니다.

## 학습 자료

학습 문서 68개 중 기본 관광·자연 기록은 68개, 별도 여행장소 참조 명부는 0개입니다. 허브 명부와 지도 명칭·250m 교차확인 후 허브 장소별 중복 정리한 후보 수입니다.

어휘 429개와 희소 가중치 1,646개를 학습했습니다. IDF는 log((1+문서 수)/(1+문서 빈도))+1로 계산하고 문서 벡터를 L2 정규화했습니다.

학습에는 이름, 알려진 분류, 주소, 실제 OSM 분류 태그와 있는 원문 설명만 사용합니다. 공식 참조 카드의 편집 태그와 편집 소개문은 관측 설명으로 학습하지 않습니다.

## 검증 범위

교차확인을 통과한 attraction만 색인에 포함합니다. 분류 미확인 reference는 관광 검색에서 제외합니다. 전체 지도 태그의 음식점·상점·숙박·일반 시설 검토와 음식 인허가 명칭 충돌 검토를 적용합니다. 문자 관련도는 추천 정확도 평가가 아니며 라벨이 있는 사용자 선호 검증은 아직 없습니다.

검색은 지역·분류·지도 범위·테마·선택적 위치를 지원합니다. 원시 GPS를 로그나 파일에 남기거나 응답 및 cursor에 넣지 않습니다. cursor는 공개 모델 버전과 다음 offset만 포함합니다.

## 과거 집계 모델 비교

| 모델 | 서비스 선택 | 검증 및 테스트 근거 |
|---|---|---|
| 집단 소비 | audience_mean | 테스트 구성비 MAE 실험 0.01601372, 평균 기준 0.01593516 |
| 승차 시간대 | weekday_bucket_mean | 테스트 시간당 MAE 실험 109.9577, 평균 기준 86.4884 |

선택은 각 모델의 기존 검증 구간 오차를 기준으로 했으며 기존 테스트를 재탐색하지 않았습니다. 관광 TF-IDF의 성능으로 위 집계 모델 수치를 제시하면 안 됩니다.

## 출처와 제한

- 빅데이터 명부와 지도 기록의 정규화 명칭·250m 위치가 일치하고 보수적 분류 검증을 통과한 후보만 사용합니다.
- 허브 1349는 식당·숙박도 포함된 분류 미확인 여행장소 명부입니다. 같은 명칭의 중복 기록과 좌표·주소 불일치가 있어 명칭·250m 범위 교집합의 근거로만 사용합니다. 행의 고유 장소성·명부 주소 정확도·공식 지정 관광지·현재 운영을 보증하지 않습니다.
- 동일 명칭·근접 지도 기록을 후보 그룹 한 곳으로 정리하고 명부의 복수 근거 행을 모두 보존합니다. 분리된 지도 그룹이 같은 명부 행으로 경쟁하면 제외합니다.
- 관광 TF-IDF는 교차확인 후보의 문자 검색 모델입니다. 인기·만족도·방문량을 예측하지 않습니다.
- 전체 OSM 원본 태그에서 음식점·숙박·상점·일반 시설을 검토합니다. generic 관광 태그와 음식 인허가 명칭이 충돌하면 보류합니다.
- 공개 좌표는 실제 입구·개방·예약·요금·도로 접근을 검증한 위치가 아닙니다.
