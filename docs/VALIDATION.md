# 최종 제출본 검증과 해석 범위

기준일은2026-11-08 한국시간이다. 현재동작검사·기존모델품질평가·처리량시험을구분한다. 데이터와모델을새로학습하거나임계값을완화해통과시킨작업이아니다.

## 현재 제출 코드의 회귀 검사

Windows 동봉 Python3.13으로 수집한448개 테스트 중 **현재 범위426개 실행통과**, **옛 실험22개는사유를명시해미실행**이다. `tests/release_scope.json`에정확한테스트ID·사유를적었다. 현재운영코드의assertion을줄이거나새실패를자동제외하지않는다.

미실행은운영에서제외한버스·v20후보실험이요구하는모델/연구파일과,현재복구본에없는TF-IDF고정22질의원본에대한검사다. 처음전체검사에서이누락을확인하고구분했다. 기존448개가모두통과했다고표현하지않는다. 현재모델입력·출처무결성·관광자격·동의·코스·기온·꽃·검색·플랫폼검사는계속실행한다.

Node기반 UI동작29개와JavaScript문법18개, 합계47개검사도통과했다. 브라우저DOM모의검사이므로실제모바일·위치권한창·모든OS브라우저의전수시각검사와는다르다. 별도플랫폼/검색/GPU계약48검사는위범위와겹치므로합산하지않는다.

### 재실행 명령

```powershell
# Windows: 전체배포파일해시검사
.\runtime\python.exe .\scripts\verify_submission.py
# 또는 .\runtime\python.exe .\dev.py check

# Python회귀만 실행
.\runtime\python.exe .\dev.py test --python-only

# Node가준비된경우 UI검사까지실행
.\runtime\python.exe .\dev.py test --node C:\실제Node경로\node.exe
```

```bash
# Ubuntu: 설치후
.venv-linux/bin/python scripts/verify_submission.py
.venv-linux/bin/python dev.py test --python-only
# Node가설치되어있으면
.venv-linux/bin/python dev.py test --node "$(command -v node)"
```

설치된Linuxvenv/vendor·브라우저데이터는정적제출명세와구분한다. 파일검사는동봉파일을변경하지않고SHA256을비교한다. 일반실행을위해재학습이나과거Git복구를할필요가없다. 손상시제출ZIP전체를새폴더에다시풀면된다.

## Windows 실제 실행 확인

개발PC의Windows에서동봉런타임과staging소스로 **49개HTTP요청**을검사했다. CPU기능46개와선택DirectML3개로, 페이지·음식1048/1047·기후·꽃·규칙상담·공식검색·공개출발지확인·자동/수동코스·오프라인도로·제외API정책을포함한다. 실제E5 CPU검색과GPU커널·상주·질의카운터증분도확인했다.

오프라인도로5,925선과실제경로470점/약6.934km를확인했다. 허브11종·CSV14개안내가최종config와일치했다. 모델·원본·DB274파일의전후해시가같았다. 시험서버는8805의소유프로세스만종료했고기존8765서비스는사용하지않았다.

이검사는실제센터PC의응답성능시험이아니다. 실제GPS와라이브외부날씨API를사용하지않았다. 초기sandbox연결제약·대표관광지subset을전체목록으로가정한테스트준비오류는서비스오류와구분해작업증거에보관했다.

## Ubuntu 실제 실행 확인

Windows의WSL·OS기능을변경하지않고휴대형QEMU TCG에서공식 **Ubuntu24.04.5 LTS / Python3.12.3**를부팅했다. 동봉21Linuxwheel과pip으로오프라인설치한뒤앱을실행해 **26개HTTP기능검사**를통과했다.

8개페이지,음식·외식,기후·꽃,규칙상담,공식검색,자동3곳코스,오프라인도로,실제E5 CPU검색2질의,프로세스RSS진단,날씨off·퇴역기능정책을확인했다. NumPy2.3.5·ONNX Runtime1.31.1·tokenizers0.22.2가Linux전용경로에서로드됐다. 코드/config/자료/모델341파일전후해시와임계값0.86이유지됐다.

게스트앱과소유QEMU가종료됐고원본Ubuntu이미지해시도같았다. VM에는최종선별에서빠지는미사용과거원본일부가있었으나해당자료를운영기능의검사입력으로쓰지않았다. 최종본에서는운영원본·모델·코드의해시와ZIP추출후동작을별도로확인한다.

게스트브라우저렌더·실제GPS권한·LinuxGPU·라이브Open-Meteo는검사범위가아니다. **VM속도를센터처리량으로해석하지않는다.** Ubuntu추가지원은CPU실행기준이다.

## 기존 GPU 상주 부하 시험

2026-11-08 개발장비i9-13980HX/RTX4090Laptop16GB/RAM64GB에서33구간·4,560요청의HTTP/형식오류0을기록했다. GPU의미검색32입력P951.45초,혼합32입력0.99초,무거운8곳코스4입력1.39초·16입력5.55초다. 동시입력은처리중+대기중이며일정도착률·동시사용자수나GPU배치크기를뜻하지않는다.

RAM생애최고3.63GiB,전용VRAM표본최고0.75GiB,공유GPU시스템RAM0.55GiB를구분했다. OS·브라우저는프로세스수치에포함하지않고공유RAM을WorkingSet에단순합산하지않는다. RAM6GiB·VRAM2GiB와일반4/무거운2입력은설계안으로서실제예약·센터보장값·이번에적용한제한이아니다. 공식센터GPU는3GB형으로확인됐다. 미래센터현장시험을약속하지않는다.

## 공개 검증 기록

`docs/validation/`에현재Windows·Ubuntu기능결과,회귀요약,배포파일검사와기존부하시험요약을둔다. 공개복사본의개발PC절대경로는표시용경로로치환할수있으나검사수·판정·자산해시는유지한다. 타인게시글의원시수집본·가상머신디스크·임시로그는최종ZIP에동봉하지않는다.

## 최종 제출본 재점검

2026-11-08 최신 제출 ZIP을 새 폴더에 풀어 동봉 파일 2,990개의 크기·SHA256과 ZIP CRC를 먼저 확인했다. 이 복사본에서 Python 현재 범위 426개 실행 통과(총448개 중 과거 실험22개 사유 명시 미실행), UI 동작29개와 JavaScript 문법18개를 다시 통과했다.

동봉 Windows 런타임의 실제 서버에서 CPU46개·선택 DirectML3개, 합계49개 HTTP 검사를 다시 통과했다. 실제 의미 검색, GPU 커널·상주·질의 카운터, 자동/수동 일정, 공개 출발지 확인, 오프라인 도로 경로, 음식·기온·꽃·자료 안내를 확인했다. 원본·모델의 전후 해시가 같았고 소유 테스트 서버는 종료했다. 개인 GPS와 외부 예보 API는 사용하지 않았다.

README에 두 OS의 빠른 실행, 직접 복사할 파일 검사·회귀 명령, 정상 결과 해석, 공개 출발지 확인 시나리오와 재설치 절차를 보강했다. Windows 런처의 누락 문서 안내만 고쳤고 두 cmd의 실제 --help 호출·인수 전달을 확인했다. Linux 설치·실행 코드와 wheel·데이터·모델은 이전 실제 Ubuntu 검증본과 동일하여 기존26개 결과를 유지한다. 이번 개정에서 Ubuntu VM을 새로 실행한 결과로 표기하지 않는다.

상세 요약은 `validation/final_submission_check.json`을 따른다. 이 기능 검사는 새 학습·추천 정확도 평가·센터 처리량 시험이 아니다. 최종 ZIP의 전체 파일 명세와 체크섬은 패키징 후 별도로 검사한다.
