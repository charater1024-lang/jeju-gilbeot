# 공식 관광 안내를 이용한 장소 소개 보강

확인일: 2026-10-29. 교차확인 정책으로 채택된 관광 후보 68곳을 대상으로 조사했다. 공식 관광 안내의 사실을 짧게 재서술한 소개를 62곳에 연결했다. 59곳은 제주관광공사 비짓제주, 3곳은 한국관광공사 대한민국 구석구석을 근거로 한다. 정확한 설명을 확인하지 못한 6곳에는 다른 장소의 설명이나 지도 태그를 관광 소개로 대신 붙이지 않는다.

## 제주데이터허브 자료의 실제 필드

기존 다운로드 `data_raw/hub/hub_1349_5802.csv`의 실제 열은 `장소명, 도로명주소, 위도, 경도, 수정일시, 지번주소`다. 저장된 `metadata_1349.json`의 데이터 설명에는 ‘장소 상세 설명’ 제공이라는 문구가 있지만, 실제 받은 CSV와 메타데이터의 CSV 미리보기에는 소개문 열이 없다. 파일에 없는 설명을 허브에서 내려받았다고 표시하지 않는다.

이 명부에는 관광지 이외의 식당·숙소·여행 메모도 포함된다. 따라서 기존 지도·허브의 명칭 및 250m 위치 교차확인 정책은 유지한다. 이번 소개 보강은 이미 채택된 후보의 표시 정보를 개선하는 것이며, 공식 지정 관광지나 현재 운영 중인 장소라는 인증을 추가하지 않는다. 허브의 주소 오류 가능성도 기존 정책과 같이 취급한다.

## 관광 소개를 확인한 공식 출처

비짓제주 공개 관광 안내에는 실제 관광 특징과 볼거리를 설명하는 본문이 있다. 공개 검색 화면에서 장소명과 지역 문맥을 확인하고, 해당 장소의 공개 상세 페이지로 연결했다. 소머리오름→우도봉처럼 공식 페이지에서 동일 장소의 별칭을 확인한 경우와 개명·명칭 오류가 있는 경우는 연결 근거를 기록했다. 주변에 있다는 이유만으로 서로 다른 장소의 설명을 연결하지 않았다.

- [제주관광공사 비짓제주 관광정보 Open API 안내](https://m.visitjeju.net/kr/visitJejuApi): API 키를 신청하고 담당자 승인 후 발급받는 방식이다. 이번 작업에서 키를 신청하거나 인증이 필요한 API를 호출하지 않았다. 일반에 공개된 웹 안내를 조사해 짧은 사실 요약과 원문 링크를 로컬에 준비했다.
- [제주관광공사 2026년 공공데이터 목록 및 활용절차](https://ijto.or.kr/korean/Bd/view.php?bno=1509&btable=notice&lcate=&p=5): 공사의 관광정보 API 제공 경로를 확인했다. 이는 현재 구현이 승인된 API 전체 데이터를 내려받았다는 의미가 아니다.
- [한국관광공사 궷물오름 안내](https://korean.visitkorea.or.kr/detail/ms_detail.do?cotid=9de3224d-c887-40c3-acd0-8a120371161c): 정확히 대응하는 독립 관광 안내를 확인해 추가했다.

사진·리뷰·긴 본문을 복제하지 않았다. 비짓제주의 저작권 표시를 공공누리 또는 자유 재배포 허가로 해석하지 않는다. 화면의 소개는 원문 인용문이 아니라 공식 안내에서 확인한 사실의 짧은 편집 요약이며 제공기관과 원문 링크를 함께 표시한다. 원문 사진은 이번 보강에 사용하지 않는다.

## 수록 자료와 재현

| 파일 | 내용 |
| --- | --- |
| `data_reference/tourism_guides_v12.json` | 62개 소개, 공식 출처, 확인일, 원문 식별자, 연결 근거 및 누락 목록 |
| `data_raw/tourism/v12/official_fields/*.json` | 공개 응답의 SHA256, 제목·식별자·주소 등 최소 출처 필드. 비짓제주 도입부는 최대 20단어로 제한하고 긴 본문·리뷰·사진은 저장하지 않음 |
| `data_raw/tourism/v12/search/*.json` | 실제 공개 검색 URL, 검색 결과의 관광 안내 링크·이름 |
| `data_raw/tourism/v12/north_east_guides.json` | 북·동부 및 기존 대표 장소 40개 소개 |
| `data_raw/tourism/v12/root_south_west_guides.json` | 남·서부 12개 소개 |
| `data_raw/tourism/v12/extra_south_west_guides.json` | 추가 9개 소개와 귀덕궤물동산 미확인 근거 |
| `data_raw/tourism/v12/supplemental_guides.json` | 한국관광공사 궷물오름 1개 소개 |
| `data_raw/tourism/v12/coverage_audit.json` | 채택 68곳 대비 62곳 수록 및 미확인 6곳 |

`author_guides.py`는 검토한 40개 편집 요약과 캐시를 묶는다. `merge_guides.py`는 네 묶음을 합치고 승인 후보 ID, 중복, 소개 길이, 공식 출처 호스트와 요약 방식, 누락 수를 검사한다. `fetch_official.py`와 `fetch_kto_public.py`는 명시된 공개 원문 URL의 최소 출처 정보만 저장하는 조사 보조 도구이며 웹 서비스 실행에 필요하지 않다. 기존 캐시를 재사용한다.

## 이름·상태를 구분한 사례

| 기존 후보명 | 공식 안내와 표시 기준 |
| --- | --- |
| 소머리오름 | 공식 우도봉 안내의 쇠머리오름 별칭과 장소 문맥을 확인 |
| 넥슨컴퓨터박물관 | 현 공식 제목 넥슨뮤지엄을 소개문에 설명 |
| 박물관은 살아있다 | 현 공식 제목 K-아일랜드제주를 소개문에 설명 |
| 금능식물원 | 좌표·주소·장소 문맥은 금능석물원에 대응. 식물원이란 잘못된 설명을 만들지 않고 공식 명칭을 명시 |
| 선녀탕 | 황우지해안 원문에서 황우지선녀탕을 확인. 공식 자료의 낙석·접근 통제 안내를 함께 표시 |
| 하모해수욕장 | 공식 원문에 모래 유실과 돌출 암반으로 해수욕장 폐장 기록이 있어 물놀이 방문을 권하지 않는 문구 포함 |
| 유리의성 | 개별 비짓제주 페이지에 본문이 없어 한국관광공사 2020년 2월 여행기사를 이용. 역사 자료라는 시점을 명시하고 현재 체험 운영을 보장하지 않음 |
| 이중섭미술관 | 공식 안내의 확충 공사·임시 전시 장소를 확인하도록 설명 |
| 사려니숲길입구 | 연결 원문은 숲길 전체 안내이므로 실제 출발 입구와 반환 동선은 별도 확인하도록 설명 |

영업시간·요금·실시간 개방·예약 가능 여부를 새로 추정하지 않았다. `retrieved_at`은 자료 확인 날짜이고 `current_operation_verified:false`는 현장 운영을 실시간 검증하지 않았다는 의미다. 명시된 통제·이전·역사 자료 표시는 해당 원문의 기록에 근거한다.

## 공식 소개를 확인하지 못한 6곳

- 우도박물관: 같은 장소에 정확히 대응하는 공식 관광 소개 미확인.
- 한울랜드: 정확한 공식 관광 소개 미확인. 이름이 유사한 농업회사법인한울제주를 임의 연결하지 않음.
- 라이트아트페스타: 정확한 공식 관광 소개 미확인.
- 노로오름: 주변 천아숲길 안내의 언급은 있으나 해당 오름 자체의 공식 설명 미확인.
- 제주미니랜드: 정확한 공식 관광 소개 미확인. 별도 관광지인 제주공룡랜드를 연결하지 않음.
- 귀덕궤물동산: 공식 걷기 안내의 경유지명은 확인했으나 자체 경관·시설 설명 미확인.

## 모델·챗봇에서의 사용

소개문은 정적 로컬 참조 정보다. 실행 중 LLM이나 외부 API를 호출하지 않는다. 기존 관광 검색 모델의 후보 ID에 검토된 소개를 덧붙이며, 편집 요약을 방문 관측 자료나 선호 학습 정답으로 재학습하지 않는다. 수록 수 62는 준비한 공식 출처 기반 소개 수이며, 학습 데이터 수·실시간 인기 순위·현장 확인 수가 아니다.
