관광지 추천은 제주데이터허브 명부와 지도에서 이름·위치가 함께 맞고 관광 분류가 확인된 장소만 사용합니다. 이름만 비슷하거나 식당·숙박·일반 시설인 기록은 관광지로 추천하지 않습니다. 음식 업종과 버스 시간대의 과거 집계 자료를 학습해 경향을 보여줍니다. 개인의 취향이나 실시간 인기도는 예측하지 않습니다. 저장한 실제 관광지의 경로는 시간과 비용 조건을 검색해 구성하며 관광객 인기를 학습한 결과가 아닙니다. 음식점 목록은 과거 인허가 자료이며 맛이나 현재 인기도를 뜻하지 않습니다. 이동 시간은 좌표 간 거리로 계산한 추정값입니다. 버스 시간표가 연결되지 않았다면 버스 경로를 생성하지 않습니다.
