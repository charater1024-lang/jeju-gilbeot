# v3 검증 결과 — 2026-10-27

## 통과 항목

- Python 3.12 개발 런타임 자동 테스트 52개 통과.
- 배포용 공식 CPython 3.13.17 Windows x64 휴대용 런타임에서도 같은 52개 통과.
- 실행 ZIP을 새 폴더에 추출한 뒤 포함된 Python으로 데이터 검증·두 집단 소비 분석·승차 패턴·장소 검색·실제 장소 경로 생성을 오프라인 검증했다. 네트워크 연결을 차단한 상태에서 외부 연결 시도 0개였다. 최초 포장 시 빠진 필수 표준 라이브러리 ZIP은 수정했고, 수정본에서 독립 검증을 통과했다.
- 휴대용 런타임으로 실제 서버 기동 후 HTTP 요청 16개 통과. 집단 분석·이동 패턴·추가 장소·식당·주차 참조·일정 생성·잘못된 입력·원본 파일 노출 제한을 포함한다.
- 실제 Chrome에서 도민/관광객 경향 변경, 추가 장소 검색·저장, 실제 장소 일정 생성, HTML 파일 저장, 새 여행 시작과 재로드 후 초기화 상태를 확인했다.
- 실제로 내려받은 `jeju-gilbeot-2026-10-27.html`(2,599바이트)에 장소명·주소·원자료 링크·비용 미확인·거리 추정 안내가 포함됨을 확인했다. 브라우저 다운로드 이벤트 도구는 완료를 잡지 못했으나 다운로드 폴더의 파일로 별도 검증했다.
- 390×844 모바일 화면에서 가로 넘침 없이 폼·시간당 비교 결과가 표시됐다. 임시 viewport 설정은 해제했다.
- 데스크톱에서 깨진 이미지 0개·가로 넘침 없음. 최종 JavaScript 문법 검사 통과.
- 가파도·차귀도·마라도 별칭/좌표·한라산 정상은 자동차 일반 일정 계산을 제한했다. 한라산CC리조트·백록담제주특산품 같은 본섬 상호의 과잉 차단도 수정했다.
- CSV 원본 8파일·독립 ID 7개·512,511,909바이트. 추가 원본 2개는 공식 첨부에서 취득했다. 원본은 실행 ZIP에 넣지 않고 로컬에 보존한다.

## 성능 측정 범위

현재 개발 PC Windows 11의 Python 3.13.17에서 warm 직접 함수 호출을 측정했다. HTTP·브라우저의 전체 메모리나 센터의 실제 i7-8700 실측이 아니다.

| 호출 | 반복 | p50(ms) | p95(ms) |
|---|---:|---:|---:|
| 소비 경향 + 식당 예시 | 40 | 27.494 | 29.775 |
| 과거 승차 패턴 | 100 | 0.303 | 0.885 |
| 장소 검색 | 100 | 5.565 | 6.59 |
| 실제 장소 8곳 순서 탐색 | 5 | 95.918 | 103.289 |

해당 프로세스 작업 집합 26,865,664바이트, 모델 두 개 합계 17,998바이트, SQLite 11,030,528바이트. GPU 사용과 외부 API 호출은 없다. 약 498MB 원본 버스 CSV는 요청 때 읽지 않는다.

## 남은 현장·서비스 검증

센터의 실제 OS·UCRT·보안정책·동일 사양의 현장 성능·다음 이용자로 전환하는 운영 절차는 확인이 필요하다. 저장 장소는 탭 세션에 보관하지만 브라우저 복원 정책에 따라 유지될 수 있어 수동 초기화를 운영 절차에 포함한다. 내려받은 일정 파일은 세션 초기화와 별도로 관리한다.

원자료의 소비는 2025.06, 일반 승차는 2025.10.26까지의 과거 관측이다. 식당 현재 영업, 개별 맛집 인기, 실시간 혼잡, 실제 도로 길찾기·버스 시간표·전체 여행 예산은 검증하지 않았다. 두 ML 후보는 기준모델보다 MAE가 높아 서비스에서 평균 모델을 사용하며 실패를 숨기지 않는다. 구체적인 학습·테스트 지표는 `09_실데이터모델검증.md`와 모델 JSON을 참고한다.
