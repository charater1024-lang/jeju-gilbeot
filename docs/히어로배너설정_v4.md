# 메인 풍경 배너 설정

메인 사진 6장의 순서와 표시값은 `config/hero_slides.json`에서 편집한다. 브라우저는 로컬 `/api/hero-slides`로 설정을 읽는다. 파일 저장 후 페이지를 다시 읽으면 반영된다. 화면에서 관리자 로그인·사진 업로드·광고를 관리하는 기능은 아직 구현하지 않았다.

`slides`에는 위 6개를 중복 없이 모두 넣는다. 배열 순서는 바꿀 수 있다. 각 항목의 `id`, `image`, `source_id`, `name`, `region_label`은 등록값과 정확히 같아야 한다. 지역 등록값은 각각 성산 동부·제주 북부 · 조천·한림 서부·조천 중산간·서귀포 남부·성산 동부다. 사진의 저작자·라이선스는 기존 사진 출처 문서와 함께 유지한다.

## 편집 가능한 값

- `schema_version`은 숫자 1로 유지한다.
- `interval_ms`는 5000부터 12000까지의 정수다. 기본값 5000은 약 5초 간격이다.
- `autoplay`는 따옴표 없는 JSON 불리언 `true` 또는 `false`다.
- `caption`은 공백만으로 구성되지 않은 문자열이며 공백 제거 전 JavaScript 문자열 길이가 60 이하여야 한다. 텍스트로 표시된다.
- `focal_x`, `focal_y`는 각각 0부터 100까지의 유한한 숫자다. 사진 배경의 가로·세로 초점 위치 비율이며 지도 좌표가 아니다.
- `href`는 `#destinations`, `#regions`, `#planner`, `#sources` 중 하나만 허용한다. 외부 주소나 임의 앵커는 허용하지 않는다.

설정이 잘못되거나 응답을 읽지 못하면 확인된 기본 사진 6장으로 돌아간다. 첫 사진도 읽지 못하면 기존 정적 배너를 유지한다. 임의 외부 이미지 주소를 설정해 사진을 추가할 수 없다.

이전·다음·선택 점·재생/정지로 조작할 수 있다. 마우스나 포커스가 배너 조작부 안에 있으면 잠시 멈추고, 배경 탭에서도 멈춘다. 동작 줄이기 설정에서는 자동 재생을 기본으로 끈다. 이 동작은 파일의 `autoplay`가 true여도 적용된다.

향후 광고·콘텐츠 관리 화면을 추가하려면 관리자 인증, 업로드와 파일 검증, 출처·라이선스 관리, 미리보기·게시 절차를 별도로 구현해야 한다. 현재 범위는 검증된 로컬 풍경의 파일 설정이다.
