## 신뢰 기준과 개인정보

관광 원본 68곳과 기존 신뢰 정책 JSON을 보존했습니다. 2026-11-03 기준 기존 정책을 통과하는 관광 후보는 40곳입니다. 정책의 별도 예외 10곳은 현재 폐쇄를 확정한 목록이 아니라 기존 기록과 방문 조건의 추가 검토가 필요한 목록입니다. 검색과 장소 열람은 유지하고 정상 일정으로 제시하는 단계에서 확인을 요구합니다. 선택 장소를 알리지 않고 삭제·대체하지 않습니다.

음식점은 별도 검색에서 선택한 위치 참조로 유지합니다. 관광 신뢰정책을 통과했다고 표시하지 않으며 현재 영업·메뉴·요금은 미확인입니다. 실제 기기 위치를 수집한 검증은 없고 공개 장소 좌표와 모의 위치만 사용했습니다. 출발지 정밀 좌표·개인 이름을 HTML 일정에 넣지 않는 기존 동작을 유지했습니다.

## Agent와 모델의 실제 범위

현재 구현은 머신러닝 검색·출처 검증·제약 계산을 중앙에서 연결하는 추천 워크플로입니다. 런타임 LLM과 자율 도구 선택은 사용하지 않습니다. 짧은 요청 표현 처리는 정해진 규칙이며 자유로운 자연어 상담이나 복합 조건 해석을 제공한다는 뜻이 아닙니다.

소비·승차 모델을 다시 학습하거나 성능 수치를 변경하지 않았습니다. 기존 허용오차 내 비율인 소비 ±1퍼센트포인트 87.5%, 승차 관측값 ±20% 약 82.53%는 v14 후향 평가 수치입니다. 관광 추천 정확도나 개별 장소 인기도로 전용하지 않습니다.
