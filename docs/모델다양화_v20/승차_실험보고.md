# 실제 승차자료의 다양한 학습 조합 비교

2026년 11월 4일. ±20% 허용오차, 원자료 일반승차와 기존 대상 집합을 유지한 후보 실험입니다. 기존 운영모델은 이 실험에서 덮어쓰지 않았습니다.

## 모델과 사전 고정 검증

512는94개,561은97개 구성을 각각2개 시간순 검증 구간에서 학습했습니다. 가중 평균·중앙값·기하평균·절사평균·20%구간 중심, raw/sqrt/log 달력 Ridge와 상대오차 Huber, 계절 커널,561 계층 shrinkage, HistGradientBoosting squared/absolute/Poisson, RandomForest·ExtraTrees, 고정가중 앙상블을 포함합니다. 모든 후보와 선정 기준은 protocol.json으로 학습 전에 기록했습니다.

후보 선택은 기존 테스트 이전 두 구간의 평균 ±20% 적중률을 최대화하되 평균 MAE가 같은 구간 incumbent보다2% 이상 나쁜 후보는 제외했습니다. 동률은 MAE·고정 ID 순서입니다. 선정 영수증을 쓴 뒤 선정 모델 하나만 기존 시험기간에 평가했으며, 시험 성과를 보고 재선정하지 않았습니다. 이미 보고했던 과거 테스트를 사용한 후향평가이므로 새로운 외부·현장 정확도로 표시하지 않습니다. 누락 셀은0으로 채우지 않았습니다.

512 MAE의 단위는명/시간이고561은명/통계코드·일입니다. 512의 wape_percent는 시간당 셀 비율이며, 이전 화면과 동일한 구간 인원 가중 WAPE는 wape_bucket_counts_percent로 별도 기록했습니다. 단위를 섞어 개선으로 표시하지 않습니다.

561 시험 대상은 기존250개 통계코드와28,092셀을 유지합니다. 운영 적합 대상은 최신 관측으로 선별한202개 코드이며 현재 실제 운행 노선·만차·좌석을 검증한 모델이 아닙니다. 새 자료나 미관측 미래 수요를 만들어 넣지 않았습니다.

각 모델의 모든 후보 검증 수치는 models_candidates_v20/bus/{512,561}/experiment_report.json에 있습니다. 설정·선정 고정·모델·시험 예측도 같은 폴더에 보존합니다. 고정 기준에서93%를 넘지 못한 모델은 미달로 기록합니다.

## 운영 추론과 검증

훈련에는 격리된 numpy 2.5.4, scikit-learn 1.7.2를 사용했습니다. 서비스 jeju_agent/bus_v20.py는 표준라이브러리만 사용하며 기존 런타임에는 이 패키지를 설치하지 않았습니다. 실제512 학습 구간으로8개 모델 가족을 학습해 490건에서 훈련 구현과 portable JSON 추론의 차이가 최대 6.82e-13임을 확인했습니다. 이 검사는 예측 정확도가 아니라 추론 구현 동등성 검사입니다.

입력은 날짜의 요일·월·일·연간 주기와 적합 구간에서만 계산한 그룹 통계입니다. 검증·시험 관측값의 lag나 미래 날씨를 입력하지 않습니다. HGB는early_stopping=False로 임의 분할 검증을 사용하지 않았습니다.

근거 문서는 [scikit-learn 시간순 검증 예시](https://scikit-learn.org/stable/auto_examples/applications/plot_time_series_lagged_features.html), [HistGradientBoostingRegressor](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.HistGradientBoostingRegressor.html), [RandomForestRegressor](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.RandomForestRegressor.html)입니다.
