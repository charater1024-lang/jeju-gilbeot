# v8 — 위치를 함께 쓰는 상담과 기능별 페이지

센터 PC에서 실행하는 로컬 여행 웹사이트입니다. 기존 데이터·TF-IDF 모델·규칙 기반 상담을 유지하고, 상담의 주변 추천과 기능별 화면을 연결했습니다. 별도 LLM이나 GPU 추론은 사용하지 않습니다.

## 다섯 화면

| 메뉴 | 주소 | 할 수 있는 일 |
|---|---|---|
| 제주 둘러보기 | `/` | 5초마다 바뀌는 제주 풍경, 대표 관광지·지역 필터·저장 |
| 지도·먹거리 | `/explore` | 관광·음식 검색, 지도·경로, 내 위치/기준 장소 선택 |
| 내 여행 | `/planner` | 모은 여행지로 일정 만들기, 일정 저장, 이동 시간대 참고 |
| 길벗 상담 | `/chat` | 짧은 질문·메뉴로 관광지·먹거리·장소 정보 안내 |
| 데이터 안내 | `/about` | 모델의 학습·검증 범위, 출처와 데이터 한계 |

지도 화면의 명부 검색·주차장·업종별 소비 경향은 **이름·주소와 음식 소비 경향으로 더 찾기**를 펼치면 보입니다. 상단 메뉴와 홈의 세 가지 시작 링크로 필요한 화면을 선택하세요. 예전 `#map-explorer`, `#planner`, `#sources` 주소도 해당 화면으로 연결됩니다.

메뉴 이동과 브라우저 뒤로/앞으로는 현재 탭의 대화·모은 장소·검색 조건을 유지합니다. 새로고침·탭 종료 후에는 복구를 보장하지 않으며, 이 앱은 이를 파일이나 브라우저 저장소에 기록하지 않습니다. 체험 종료 시 **새 여행 시작**으로 초기화하세요.

## 상담에서 주변 추천 받기

1. **길벗 상담**에서 `내 주변 관광지 추천`, `가까운 고기국수 식당`, `근처 해변 추천해 줘`처럼 물어봅니다.
2. 현재 기준 위치가 없고 아직 건너뛰지 않았다면 앱의 위치 사용 안내가 열립니다. 안내를 열거나 권한 상태를 읽는 것만으로 좌표를 요청하지 않습니다.
3. **동의하고 위치 요청**을 누른 뒤 브라우저에서 허용하면 추정 위치를 받습니다. 브라우저에 허용·차단이 기억되어 있으면 새 권한창이 생략될 수 있습니다.
4. 수신한 제주 내 위치를 기준으로 기본 **직선거리 20km** 안의 후보를 안내합니다. 카드에서 거리·주소·출처를 확인하고 **지도 보기 / 상세 보기 / 여행에 담기**로 이어갑니다.

기준 위치가 이미 있으면 지도와 상담이 같은 탭에서 이를 공유합니다. 상담의 **내 위치 사용 / 내 위치 다시 확인**으로 위치를 직접 요청할 수도 있습니다. 실제 기기 좌표 수신은 PC·브라우저·OS 환경에 따라 실패할 수 있습니다.

**기준 장소 선택**은 지도 화면의 선택 메뉴로 이동합니다. 제주공항·대표 관광지를 고르면 그 장소가 거리의 기준이며 실제 사용자의 위치를 알아낸 것이 아닙니다. 상담 상태줄에도 선택한 장소와 **실제 내 위치가 아닙니다**가 표시됩니다. 기기 위치를 쓰려면 별도로 **내 위치 사용**에서 동의해야 합니다.

## 동의하지 않거나 위치를 받지 못한 경우

안내창을 닫거나 **기준 장소로 찾기**를 선택하면 위치를 사용하지 않습니다. 브라우저 거절·시간 초과·수신 실패·제주 밖의 위치도 가까운 제주 후보를 계산한 것처럼 처리하지 않습니다. 지역·음식·테마 검색으로 계속 이용하거나 수동 기준 장소를 고를 수 있습니다.

위치를 건너뛴 뒤에는 매 질문마다 같은 안내를 반복하지 않습니다. 필요하면 상담의 **내 위치 사용**을 누릅니다. **위치 지우기**는 상담과 지도에서 공유하는 기준 위치를 제거합니다. 브라우저 권한 자체의 해제는 사이트 설정에서 별도로 합니다. 팝업이 없을 때의 자세한 설정은 [위치 동의와 브라우저 설정](13_위치동의와브라우저설정.md)을 참고하세요.

## 추천의 의미와 데이터 사용

장소의 이름·관측 분류·원자료 태그를 기존 TF-IDF 검색 모델과 규칙으로 찾습니다. 위치가 있으면 좌표가 확인된 기록만 반경 검색에 넣고, 음식·테마 관련도를 구분한 뒤 같은 관련도 단계에서는 가까운 순으로 안내합니다. 단순 주변 검색은 직선거리 순입니다. 위치가 없을 때는 가까운 순서라고 표시하지 않습니다.

거리는 도로 이동 거리나 소요 시간이 아닙니다. 음식 태그나 상호의 관련성은 실제 메뉴·맛·인기·현재 영업을 검증한 결과가 아닙니다. 특정 장소 이름을 기준으로 한 `함덕 주변 카페`와 사용자의 `내 주변 카페`를 혼동하지 않도록 안내를 구분합니다. 지도를 통해 원하는 기준 장소를 직접 확인할 수 있습니다.

사용자 좌표는 탭 메모리에 두고, 추천 요청 시 이 PC의 로컬 서버에 보내 계산에만 사용합니다. 일반 대화 상태·파일·모델·일반 요청 로그에 저장하지 않습니다. 좌표를 텍스트로 직접 질문에 넣으면 대화 내용이 될 수 있으므로 **내 위치 사용**이나 기준 장소 메뉴를 이용하세요. 새 여행 시작·위치 지우기·탭 종료 시 앱의 공유 위치를 제거합니다. 온라인 지도에는 기기 위치 마커나 해당 위치가 담긴 경로를 보내지 않습니다. 브라우저·OS 자체의 위치 서비스는 네트워크를 사용할 수 있습니다.

## 확인할 동작

| 상황 | 확인할 결과 |
|---|---|
| 첫 화면·상담 열기 | 자동 기기 위치 요청 없음 |
| 위치 없는 주변 추천 질문 | 앱의 위치 안내가 먼저 표시됨 |
| 안내 동의 + 모의 제주 좌표 | 20km 내 좌표 보유 후보와 직선거리 표시 |
| 안내 취소·기기 거절·수신 실패 | 위치 없이 계속하거나 기준 장소 선택 가능 |
| 제주공항을 수동 선택 | 실제 기기 위치라는 표현 없이 선택 장소 기준 표시 |
| 위치 제거·변경 중 이전 응답 도착 | 옛 기준의 늦은 응답을 적용하지 않음 |
| 추천 카드의 지도 보기 | `/explore`로 이동하고 지도 크기·장소가 갱신됨 |
| 저장 → 내 여행 → 상담 복귀 | 같은 탭에서 저장·대화가 유지됨 |
| 경로별 직접 접속·새로고침·뒤로/앞으로 | 맞는 화면과 현재 메뉴가 표시됨 |

`tests/ui_pages_v8.cjs`는 경로·뷰·메뉴·상태 유지, `tests/ui_location_context_v8.cjs`는 모의 위치 공급자의 동의·취소·철회·늦은 콜백을 확인합니다. 실제 사용자 위치를 개발 도구가 대신 요청하지 않습니다. 실제 브라우저 권한과 기기 수신 성공은 사용자가 허용한 환경에서 별도로 확인해야 합니다.
