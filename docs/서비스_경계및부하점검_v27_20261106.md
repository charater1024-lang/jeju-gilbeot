# 제주 길벗 v27 경계·부하 점검

2026-11-06, 개발 노트북에서 공개 관광 자료와 로컬 OSM 도로망을 기준으로 점검했다. 브라우저는 검증 전용 탭을 사용했고, 동시 접속과 비정상 요청은 별도 로컬 서버에서 실행했다. 파일 누락·손상 시험은 복사본에 한정했다. 운영 코드는 이번 점검에서 수정하지 않았다.

## 수정 후 재검증

| 범위 | 적용한 수정과 확인 결과 |
|---|---|
| 상담 | 지역 검색에서 공유 위치를 분리하고, 서버가 주변 검색에 위치가 필요하다고 응답한 경우에만 동의한 위치를 보낸다. 직선 반경 1~100km와 한 번에 1~5곳을 지원한다. 이름을 적은 장소의 주변은 지도에서 기준 장소를 고르도록 안내한다. 미지원 제외·접근·이동·실시간 조건은 확인 범위를 설명한다. 새 지역·음식·테마와 결과 번호가 후속 질문에 반영된다. 선녀탕 등 방문 검토 대상은 추천 카드와 상세에 사유·출처를 표시하고 상담에서 일정에 담는 동작을 제한한다. |
| 일정·지도 | 좌표 기준 초안이 조건에 맞지 않으면 로컬 OSM 도로 거리로 순서를 다시 탐색하고 최종 경로를 재검사한다. 제주목관아 07:43·1,786원, 순서가 다른 어영공원·용두암, 관광지 9곳 20:20 마감 사례가 통과했다. 10곳 이상의 도로 재탐색은 후보를 64개로 제한한다. 화면에서 1원 단위 예산을 입력할 수 있고, ‘제주목관아 추천해 주세요’처럼 확인된 장소명을 포함한 검색을 처리한다. |
| 저장 목록 | 잠시 실패한 상세 조회는 확인 대기로 보존한다. 재시도 또는 확인 대기 장소 제외를 직접 선택할 수 있다. 확인 대기 중인 장소가 있으면 전체 일정의 일부를 생략해 생성하지 않는다. 404나 신뢰 조건을 통과하지 못한 응답은 재검증 과정에서 구분한다. 복원 검사 8건을 통과했다. |
| 데이터 | 운영 점검은 실제 1047 조회에 필요한 원본과 모델을 확인한다. 1048 CSV의 누락, 0건, 합계 범위 초과를 구분하고 같은 달은 단일 월로 보여준다. 비교하는 두 달의 ‘알수없음’ 기록 범위가 다르면 표시한다. |
| 요청 처리 | 큰 숫자와 비유한 JSON 수치, 검색어의 NUL을 입력 오류로 처리한다. 본문 수신·응답 전송과 계산 슬롯을 분리하고 본문 수신은 5초로 제한한다. 정상 혼합 요청 168건이 모두 응답했고, 미완료 요청 8개와 응답을 읽지 않는 연결 8개를 각각 유지한 시험에서도 상태 확인이 1.5초 안에 응답했다. 미완료 본문은 408로 확인했다. |
